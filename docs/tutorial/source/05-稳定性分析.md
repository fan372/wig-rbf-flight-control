# 第 5 章 这架飞机本身稳不稳

模型建好了，下一个问题是：**这架飞机自己能不能飞得稳？** 如果不能，难在哪里？

这一章是全文的一个重点，因为**后面控制器为什么要那样设计，完全由这里的结论决定**。

## 5.1 配平：先找一个"什么都不动"的状态

### 什么是配平

配平就是找一个状态和一组控制量，使得**所有导数都等于零**：

```
dV/dt = dγ/dt = dα/dt = dq/dt = dh/dt = 0
```

物理上就是：**飞机保持水平匀速直线飞行，永远这样飞下去。**

这和你做静力学题时"求平衡位置"是同一件事。

### 配平方程

令 γ = 0（平飞）、q = 0（不转），代入第 4 章的方程：

```
(1) 沿航迹：T·cos(α+i_T) - D = 0
(2) 法向：  L + T·sin(α+i_T) - m·g = 0
(3) 力矩：  M = 0
```

**三个方程，三个未知数**：迎角 α、升降舵 δ_e、推力 T。

（速度和高度是我们指定的，不是未知数——我们说"在 18 m/s、0.2 米高度上配平"，就是要找这一刻的 α、δ_e、T）

**为什么方程 (1) 里没有重力项**：因为 γ = 0 时 `sin(γ) = 0`，重力在航迹方向没有分量 √
**为什么方程 (2) 里是 `-m·g` 而不是 `-m·g·cos(γ)`**：因为 γ = 0 时 `cos(γ) = 1` √

### 怎么解

这三个方程**互相耦合**，而且是非线性的：

- α 影响升力和力矩
- δ_e 影响力矩，也轻微影响升力
- T 影响两个力方程，还通过推力偏置影响力矩

没法手算，得用数值方法。本工程用 MATLAB 的 `fsolve`（信赖域算法）。同时写了一个**阻尼牛顿法**作为后备——因为 `fsolve` 属于 Optimization Toolbox，不是所有安装都有。

**牛顿法的思想**（你本科数值分析学过）：

```
1. 猜一个解 x0
2. 算残差 r = f(x0)  （离零有多远）
3. 算雅可比矩阵 J = ∂f/∂x  （残差对解的敏感度）
4. 解线性方程 J·Δ = -r 得到修正量
5. x1 = x0 + Δ
6. 重复直到残差足够小
```

**为什么要"阻尼"**：直接走满一步可能冲过头甚至发散，所以每次只走一部分（线搜索）。这是工程实现里的常见做法。

## 5.2 配平结果说明了什么

在 18 m/s 下对不同离地高度配平：

| h (m) | 迎角 (°) | 升降舵 (°) | 推力 (N) | 升阻比 L/D |
|---|---|---|---|---|
| 0.05 | 3.11 | -4.70 | 7.08 | **16.6** |
| 0.15 | 3.85 | -4.44 | 8.26 | 14.2 |
| 0.25 | 4.43 | -4.17 | 9.16 | 12.8 |
| 0.35 | 4.82 | -3.92 | 9.80 | 12.0 |
| 0.50 | 5.18 | -3.61 | 10.43 | 11.2 |

（这些是"真实对象"的结果）

**三个观察**：

**观察 1：升阻比随高度增加而下降。**
从 5 厘米的 16.6 降到 50 厘米的 11.2。这是地效减弱的直接后果——**飞得越低越省油**，这正是地效飞行器的价值所在。

**观察 2：迎角随高度增加而增大。**
从 3.11° 增到 5.18°。因为地效减弱了，升力线斜率降低，要产生同样的升力就得加大迎角。

**观察 3：升降舵偏角在 -3.6° ~ -4.7° 之间。**
负值意味着"后缘向上偏"，即平尾产生**向下的力**。这是常规布局飞机的常态：**平尾是"配重"，往下压，把机头抬起来平衡机翼的低头力矩**。

**这些配平量对控制器意味着什么**：如果控制器用的模型和真实对象不一样，它算出来的配平舵角就不对，会产生稳态误差。表格中"名义模型"和"真实对象"的升降舵差约 0.8°，就是控制器必须在线补偿的量。

## 5.3 线性化：得到 A、B 矩阵

配平点找到了，接下来在这个点附近做线性化（见 2.6 节）。

**做法**：用中心差分数值求偏导。

```
A 的每一列：对某个状态加一个小扰动，看所有导数怎么变
B 的每一列：对某个控制量加一个小扰动，看所有导数怎么变
```

**为什么用数值差分而不是推导解析式**：

| 方法 | 优点 | 缺点 |
|---|---|---|
| 解析推导 | 精确、快 | **极易出错**；模型一改就得重推；表达式极其冗长 |
| **数值差分** | **自动跟随模型变化；不会推错；实现简单** | 稍慢；步长要选好 |

对于有几十项气动力公式的模型，数值差分是**工程上唯一可行的选择**。

**步长怎么选**：本工程用 `Δ = 10^-6 × max(1, |x|)`。太小会有浮点舍入误差，太大会引入非线性误差。10^-6 是常用的折中。

## 5.4 模态分析：飞机怎么"晃"

对 A 矩阵求特征值，就得到飞机的**固有模态**（见 2.7 节）。

本对象在 h = 0.20 m 处的特征值：

| 特征值 | 类型 | 含义 |
|---|---|---|
| -4.44 ± 8.54j | 短周期 | 周期 0.74 s，阻尼比 0.46（良好） |
| **+0.4875 ± 0.3507j** | **浮沉-高度耦合** | **实部为正，发散！** |
| -1.58 | 高度实根 | 快速收敛 |
| -6.67 | 发动机 | 时间常数 0.15 s |
| -20.0 | 舵机 | 时间常数 0.05 s |

**两个执行器极点**分别对应发动机和舵机的时间常数，和理论值 `1/τ` 完全一致——这说明线性化程序是对的（一个很好的自检方法）。

**短周期很好，浮沉模态发散。** 下面重点分析后者。

## 5.5 发现一：高度静稳定性是负的

### 什么是"高度静稳定性"

和"俯仰静稳定性"类比：

- **俯仰静稳定性**：迎角增大时，是否产生恢复力矩（低头）？判据 `∂M/∂α < 0`
- **高度静稳定性**：高度减小时，是否产生恢复力矩（抬头，把飞机推回去）？

**稳定的条件是**：高度减小（dh < 0）-> 应该产生抬头力矩（dM > 0）-> 即 `∂M/∂h < 0`

**本工程的计算结果**（h = 0.200 m 配平点）：`∂M/∂h = +10.8157 N·m/m > 0` —— **不满足判据，高度不稳定**。

### 为什么？四项分解

这个正号是哪来的？我们把 ∂M/∂h 拆成四项（外加两项恒为零的）来看。

**先说清算法**：代码（`wig_mdh_decomp.m`）并不是照着手推公式去凑一个数，而是**把 `wig_aero.m` 里已经分开算好的每一个力矩分量，各自对 h 做中心差分**：

```
∂M_分量/∂h ≈ [ M_分量(h+Δh) - M_分量(h-Δh) ] / (2Δh),   Δh = 1e-4 m
```

其余状态冻结在配平值（这正是 Irodov 高度稳定性判据里 `∂C_m/∂h` 的定义）。所以下面每一个数字都是**程序直接输出的**，不是解析近似。

在 h = 0.200 m、V = 18 m/s 的真实对象配平点上，六个分量是：

| 分量 | 数值 (N·m/m) | 性质 |
|---|---|---|
| 机翼 | **−1.2075** | 稳定 |
| 平尾 | **+10.3302** | **主导不稳定项** |
| RAM 附加力 | +1.2208 | 不稳定 |
| 升力非线性软化 | +0.4723 | 不稳定 |
| 机体 | 0.0000 | 与 h 无关 |
| 推力线偏置 | 0.0000 | 与 h 无关 |
| **分量之和** | **+10.8157** | |

**六项相加等于总量，残差只有 1.4e-13 N·m/m**（`log_stab.txt` 与 `log_mdh.txt` 第 2 节都打印了这个自洽性校核）。这一点很重要：它说明分解是**完备**的——没有任何一项被漏掉，也没有"未计入的高阶项"这种含糊说法。分解可信，就是因为这个残差是机器精度量级。

下面逐项看物理。

**第 1 项：机翼升力变化 -> 稳定，−1.2075 N·m/m**

高度降低 -> 地效增强 -> 升力增大（`∂L/∂h = -88.676 N/m`，即每降低 1 米升力增加约 88.7 N）。

机翼气动中心在重心**前方** 2 cm（`x_acw = +0.02 m`），所以升力增大产生的是**抬头**力矩，量级就是：

```
∂M_翼/∂h ≈ x_acw × ∂L/∂h = 0.02 × (-88.676) ≈ -1.8 N·m/m
```

**负号 = 稳定**。高度降低 -> 抬头 -> 爬回去 √

这个手算值（约 −1.8）与程序中心差分给出的 **−1.2075** 同号、同量级。两者不完全相等是因为程序算的是**完整的** `M_w = z_acw·Fx_w - x_acw·Fz_w + q∞Sc·C_mac`（含少量随 α 变化的角度项），而手算只取了主导项 `-x_acw·ΔL`。**能对上就说明分解的物理机理是对的**；要引用精确数值时，用程序的 −1.2075。

但请注意这个量**很小**（约 −1.2 N·m/m，只占总量 10.8157 的约 11%），原因是力臂只有 2 cm。**这一项之所以小，就是因为气动中心只比重心靠前 2 cm**——不是因为它被什么大数抵消了。反过来说，如果为了增大这一项而把气动中心大幅前移，会同时牺牲俯仰静稳定性，得不偿失。

**第 2 项：平尾下洗变化 -> 不稳定，+10.3302 N·m/m**

这是**主因**，值得慢慢讲。

平尾在机翼后面，处在机翼的下洗气流里。配平时平尾产生的是**向下的力**（前面说过，平尾是"配重"）。

现在高度降低：

1. 地效增强，下洗角 ε 变小（因为 `ε = (ε0+ε_α·α)·κ`，κ 变小）
2. 平尾感受到的迎角 `α_t = α + i_t - ε` **变大**
3. 平尾的升力系数增大 —— 但平尾本来是**负升力**（向下），升力系数增大意味着**向下的力变小**
4. 平尾向下的力变小 -> 它的抬头力矩变小 -> **等效于低头力矩增大**

这条因果链最后一步在代数上就是：

```
∂M_尾/∂h = -l_t × ∂L_t/∂h
```

（`l_t = 0.95 m` 是尾力臂；平尾向下的力是负的，力变小即 `∂L_t/∂h < 0`，于是 `∂M_尾/∂h > 0`。）

**不必手算这个偏导数**——手算要把 `∂κ/∂h`、`∂α_t/∂h`、`∂C_Lt/∂h` 一层层串起来，每一层都是近似，算出来的数对不上程序输出（这正是本教程早期版本出过的错）。直接**引用程序中心差分的结果**：`+10.3302 N·m/m`。

**正号 = 不稳定**。高度降低 -> 低头 -> 加速下沉 ×

**第 3 项：RAM 效应 -> 不稳定，+1.2208 N·m/m**

RAM 附加力的作用点在气动中心**之后** 5 cm（`x_ram = -0.03 m`）。贴地时翼下高压区加强，RAM 附加升力随 h 减小而增大（`∂L_ram/∂h < 0`），而这个力作用在重心之后，于是产生**低头**力矩：

```
∂M_ram/∂h = x_ram × ∂L_ram/∂h = (-0.03) × (负) = 正
```

同样是不稳定的。

**第 4 项：升力非线性软化 -> 不稳定，+0.4723 N·m/m**

真实对象的升力带 `tanh` 软化（失速特性），`C_L = C_Lmax·tanh(C_L/C_Lmax)` 使实际升力略低于线性值。贴地时线性升力更大，软化吃掉的部分也更多，这个"少掉的升力"同样作用在气动中心之前——它的高度导数就贡献了这 +0.47 N·m/m。量级不大，但**不能漏**：漏掉它就会出现"分项之和 ≠ 总量"的缺口。

**第 5、6 项：机体与推力线 -> 恒为 0**

`M_fus` 只依赖动压与迎角，`M_T = z_T·T·cos(i_T)` 只依赖推力，**两者都不含 h**，所以对 h 的偏导数严格为零。把它们列出来不是为了凑数，而是为了让"六项之和 = 总量"的等式**结构上完整**。

### 合计与自洽性

```
∂M/∂h = (-1.2075) + (+10.3302) + (+1.2208) + (+0.4723) + 0 + 0
      = +10.8157 N·m/m
```

与数值计算的总量 +10.8157 N·m/m 相比，**残差 1.4e-13 N·m/m**（相对量级 1.6e-13，即双精度机器精度）。分项之和与总量**精确闭合**——这就是这套分解可信的证据。

### 这个分解随高度怎么变

把同样六个分量在 h = 0.05 ~ 1.00 m 上都算一遍（`log_mdh.txt` 第 1 节）：

| h (m) | 总量 | 机翼 | 平尾 | RAM | 升力非线性 | 平尾占比 |
|---|---|---|---|---|---|---|
| 0.050 | +14.901 | −2.301 | +15.779 | +0.760 | +0.662 | 105.9% |
| 0.150 | +12.795 | −1.539 | +12.434 | +1.332 | +0.569 | 97.2% |
| 0.250 | +8.994 | −0.955 | +8.541 | +1.026 | +0.382 | 95.0% |
| 0.350 | +6.188 | −0.621 | +5.908 | +0.655 | +0.246 | 95.5% |
| 0.450 | +4.358 | −0.425 | +4.211 | +0.410 | +0.162 | 96.6% |
| 0.550 | +3.170 | −0.304 | +3.099 | +0.264 | +0.111 | 97.8% |
| 0.800 | +1.627 | −0.153 | +1.625 | +0.104 | +0.051 | 99.9% |
| 1.000 | +1.056 | −0.099 | +1.067 | +0.057 | +0.032 | 101.0% |

三个要点：

1. **总量处处为正**：+14.901 ~ +1.056 N·m/m，即**整个使用包线内高度静稳定性都是负的**，离地越近越严重。
2. **平尾项在每一个高度上都是最大的正贡献**：+15.779 ~ +1.067 N·m/m。
3. **平尾项占总量的 95% ~ 106%**——注意它**可以超过 100%**。

**为什么占比能超过 100%**：因为机翼项是**负数**。总量是"平尾 + RAM + 非线性"这三个正项，先减去机翼项那部分稳定贡献之后的净值：

```
总量 = 平尾 + RAM + 非线性 − |机翼|
```

所以 `平尾 / 总量 = 平尾 / (平尾 + RAM + 非线性 − |机翼|) > 平尾 / (平尾 + RAM + 非线性)`。在 h = 0.05 m 处，机翼项 −2.301 相对总量 14.901 已经占了 −15%，正项的"毛和"是 17.2，于是平尾的份额被抬到了 105.9%。**占比超过 100% 不是算错，恰恰是"机翼在帮忙、但帮得不够"的量化表达。**

**结论：平尾的下洗敏感性主导了这个不稳定——在所有高度上都占总量的 95% 以上。**

### 这个结论有什么工程价值

既然知道主因是平尾，那么**改设计就能改善**：

- 把平尾抬得更高（远离机翼下洗区）
- 改用 T 型尾翼或 V 型尾翼
- 增大机翼气动中心到重心的距离（但那会牺牲俯仰稳定性）
- 加装端板，抑制翼尖涡

**但本工程不这么做**，因为我们的目标是**验证控制器能不能解决这个问题**，而不是改飞机。这也更符合"控制工程师"的角色定位。

## 5.6 发现二：浮沉模态发散

### 先看"没有地效"的情况

做一个对照实验：把地效关掉（令 κ ≡ 1，等效于无限高），重新算模态：

| h (m) | 有地效：实部 | 阻尼比 | 无地效：实部 | 阻尼比 |
|---|---|---|---|---|
| 0.05 | +0.4463 | **-0.6116** | -0.0027 | +0.0029 |
| 0.20 | +0.4875 | **-0.8118** | -0.0077 | +0.0073 |
| 0.35 | +0.4607 | **-0.9211** | +0.0002 | -0.0002 |
| 0.50 | +0.3905 | **-0.9009** | -0.0066 | +0.0083 |
| 1.00 | +0.1434 | **-0.3931** | -0.0275 | +0.0397 |

（数据取自 `log_analysis.txt` 第 3 节"纵向模态随高度变化"，`log_stab.txt` 的"逐高度扫描"表给出了同一批 h = 0.05/0.10/0.20/0.30/0.50/0.80/1.50/3.00 的点，数值一致。注意两列都是**复极点对的实部与阻尼比**；此外还有一个 h = 0.20 m 处约 −1.58 的**高度实根**，那是另一个模态，不要和这里的复极点对混在一起。）

**结论非常干净**：

- **关闭地效 -> 实部约等于零（-0.003 ~ -0.028），临界稳定**
- **开启地效 -> 实部变成 +0.14 ~ +0.49，明显发散**
- 高度越低，发散越厉害（直到某个点后缓和）

**这就证明了：失稳完全由地效引起，不是代码错误，也不是模型设置问题。**

### 用经典理论交叉验证

航空理论里有个著名的浮沉模态近似公式（**Lanchester 二状态近似**）：

```
ω_n = √2 · g / V
ζ   = 1 / ( √2 · (L/D) )
```

注意阻尼比这一条：**它用的是升阻比 `L/D`，不是阻力 `D`**。这是有量纲检查在背后兜底的——`ζ` 必须无量纲，而 `D/(m·V·ω_n)` 里 `D` 是 N、`m·V·ω_n` 是 kg·m/s²，看起来也能约掉，但只要把 `ω_n = √2·g/V` 代进去就会发现它真正的量纲是 `1/V`，**少乘了一个 V**。本工程早期版本的代码就误用了 `D/(m·V²·ω_p)`，算出 0.0029——那个数偏小 18 倍；现在 `run_00_stab_body.m` 里同时打印正确式和这个错误式作对照，就是为了防止再退化回去。

代入 h = 0.20 m 的配平结果（V = 18 m/s、L = 117.045 N、D = 8.722 N、L/D = 13.419）：

```
ω_n = 1.414 × 9.81 / 18 = 0.7705 rad/s
ζ   = 1 / (1.414 × 13.419) = +0.0527
```

理论预测：**阻尼比为正但很小（约 0.05）**，即弱阻尼、缓慢衰减——不是发散。

而"无地效"的数值结果是 ζ ≈ +0.003 ~ +0.040 —— **和理论同号、同量级，吻合**！

**这个交叉验证非常重要**：它说明我们的模型在"没有地效"的极限情况下，能退化成经典航空理论的结果。**如果对不上（比如符号相反、或量级差一个数量级以上），那说明模型里有 bug。**

### 物理图像

浮沉模态本来是"动能和势能交换"：

1. 飞机爬升 -> 动能变势能 -> 减速
2. 速度降低 -> 升力不足 -> 开始下沉
3. 下沉 -> 势能变动能 -> 加速
4. 速度增加 -> 升力增大 -> 又开始爬升

正常情况下，**阻力**会给这个循环提供阻尼（速度高时阻力大，多消耗一点能量），所以它是临界稳定的。

但在地效区，情况变了：**高度本身会强烈改变升力**。当飞机下沉时，地效给出额外升力，这个额外升力打乱了原来的能量交换节奏，**把阻尼项变成了负的**。

## 5.7 一个重要的控制器设计推论

把 5.5 和 5.6 合起来看：

| 问题 | 时间尺度 | 对控制器的要求 |
|---|---|---|
| 高度静稳定性为负 | 与高度环同量级 | 高度环必须有足够带宽和相位裕度 |
| 浮沉模态发散 | 慢（0.5 rad/s 量级） | 速度环和高度环必须协调，不能各自为政 |
| 气动参数随高度剧变 | 与飞行状态同量级 | 参数化设计不够，需要**函数逼近** |

**第三条是决定性的**：如果在 5 厘米高度调好的控制器，到了 50 厘米就不对了，而且这个变化是**非线性的**，那么：

- 单纯提高增益不行（高增益在某个高度会失稳）
- 单纯增益调度也不行（要调度的维度太多：h、V、α 都要）
- **必须让控制器自己能"学"** -> 这就引出了第 6 章的自适应控制

## 5.8 本章小结

- 配平 = 找静平衡点，三个方程三个未知数，用 `fsolve` + 阻尼牛顿法求解。
- 配平结果：**升阻比随高度增加而下降（16.6 -> 11.2）**，证明地效的价值。
- 线性化用**数值差分**，理由是不易出错且跟随模型变化。
- **发现一**：`∂M/∂h = +10.8157 N·m/m > 0`（h = 0.20 m），高度静不稳定。四项分解中**平尾下洗项 +10.3302 N·m/m，在 h = 0.05~1.00 m 全区间占总量的 95%~106%**；机翼项 −1.2075 N·m/m 是唯一的稳定贡献。分项之和与总量的残差仅 1.4e-13 N·m/m，分解精确闭合。
- **发现二**：浮沉-高度耦合模态的阻尼比在全包线内为 **−0.39 ~ −0.92**（发散）；关闭地效后恢复到约 0（−0.0002 ~ −0.028），且与经典 Lanchester 理论 `ζ = 1/(√2·(L/D)) ≈ +0.0527`（h = 0.20 m）同号同量级 —— **证明确由地效引起**。
- 推论：**参数化设计不足以应对随高度剧变的气动特性，必须用能在线学习的控制器。**
