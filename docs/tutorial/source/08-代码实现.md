# 第 8 章 代码逐文件讲解

这一章讲**代码为什么这么写**。不是把代码贴一遍，而是讲每个文件承担什么职责、为什么这样分、关键行为什么这么写。

## 8.2 为什么这么分文件

### 原则：一个文件 = 一个物理概念

对比两种做法：

| 做法 | 优点 | 缺点 |
|---|---|---|
| 全部写在一个大脚本里 | 写起来快 | 无法单独测试；改一处要跑全部；出错难定位 |
| **按物理概念分文件** | **每个文件可单独调用、单独验证；改气动不用动控制器；出错能快速二分定位** | 文件多；需要管理函数签名 |

**实战价值**：本工程调试时，正是因为 `wig_aero.m` 可以单独调用，才能打印出力的分解，从而确认"力和状态导数是自洽的"，把问题**锁定在控制器侧**。如果全写在一起，这一步根本做不了。

### 原则：参数和逻辑分离

参数全部集中在 `wig_params.m` 里，其他文件通过 `p.xxx` 访问。

**好处**：改参数不用翻遍所有文件；所有参数的物理含义集中在一处文档化。

### 原则：同名函数只做一件事

比如 `wig_ge.m` 只算地效因子，`wig_aero.m` 只算力和力矩。

**为什么要拆开**：因为 `wig_ge` 被三个地方调用（气动力、平尾、控制器），拆开后保证**三处用的是同一个地效模型**。如果各自实现一份，很容易不一致。

## 8.3 wig_params.m：参数集怎么组织

### 分层组织

```matlab
%% 环境与常量
p.g = 9.80665;  p.rho = 1.225;

%% 质量与惯量
p.m = 12.0;  p.Iyy = 1.15;

%% 机翼几何
p.b = 2.40;  p.c = 0.40;
p.S = p.b * p.c;              % 派生量：直接算出来，不重复填
p.AR = p.b^2 / p.S;

%% 地效模型
p.ge_A = 0.0641;  p.ge_n = 1.4622;

%% 控制器参数
p.ctrl.k_h = 2.00;  p.ctrl.k_hd = 0.80;  ...
```

### 几个设计决定

**决定 1：派生量当场算，不手填。**

```matlab
p.S  = p.b * p.c;        % 而不是 p.S = 0.96;
p.AR = p.b^2 / p.S;      % 而不是 p.AR = 6.0;
```

**为什么**：如果手填，改了翼展忘了改面积就会出错。让计算机算，永远不会不一致。

**决定 2：控制器参数放在子结构体 `p.ctrl` 里。**

```matlab
p.ctrl.k_h     % 而不是 p.k_h
```

**为什么**：这样可以把整个 `p.ctrl` 传给控制器函数，和对象参数 `p` 区分开。调试时想试不同增益，只要改 `p.ctrl` 就行，不影响对象模型。

**决定 3：加了 `p.is_truth` 标志。**

```matlab
p.is_truth = false;      % 名义模型
% 在 wig_truth_params 里：pt.is_truth = true;
```

**为什么**：气动函数需要知道"我现在算的是名义还是真实"。用字段而不是额外的参数，可以让函数签名保持简单。

## 8.4 wig_ge.m：地效因子

```matlab
function [kap, dkap] = wig_ge(h, span, p)
A = p.ge_A;
n = p.ge_n;
x = max(h, 0) / span;         % 归一化高度
if x <= 0
    kap = 0;  dkap = 0;  return;
end
xn   = x^n;
den  = A + xn;
kap  = xn / den;
dkap = n * A * x^(n-1) / (span * den^2);   % 对 h 的导数
```

### 为什么要有 `span` 参数

因为**机翼和平尾用的翼展不同**：

```matlab
kap_w = wig_ge(h,           p.b,  p);   % 机翼
kap_t = wig_ge(h + p.dz_t,  p.bt, p);   % 平尾（不同高度、不同翼展）
```

**为什么平尾要用不同高度**：平尾比机翼高 0.30 m（抬高安装），所以它感受到的地效比机翼弱。

**为什么平尾要用不同翼展**：地面效应本质是"地面挡住翼尖涡"，涡的尺度是各自的翼展。

### 为什么要返回导数 `dkap`

第 5 章计算 `∂M/∂h` 时需要用到。虽然本工程的主要分析用的是数值差分，但保留解析导数便于验证。

### 边界处理

```matlab
x = max(h, 0) / span;
if x <= 0
    kap = 0;  return;
end
```

**为什么**：`x^(n-1)` 当 `x = 0` 且 `n < 1` 时会发散，当 `n > 1` 时导数为 0。这里直接返回，避免数值问题。而且物理上 h < 0 就是撞地了，不做讨论。

## 8.5 wig_aero.m：气动力

这是最长的文件，因为要算的东西多。

### 整体流程

```matlab
function [F, aux] = wig_aero(x, p, flag)
% 1. 算地效因子
kap_w = wig_ge(h, p.b, p);
h_t   = h + p.dz_t;
kap_t = wig_ge(h_t, p.bt, p);

% 2. 算有效升力线斜率
aw = p.a0  / (1 + p.a0  * kap_w / (pi * p.AR  * p.e));
at = p.a0t / (1 + p.a0t * kap_t / (pi * p.ARt * p.et));

% 3. 算机翼气动
CLw_lin = aw * (alpha - p.aL0);
CDi_w   = CLw_lin^2 * kap_w / (pi * p.AR * p.e);
CDw     = p.CD0 + CDi_w;

% 4. 真实对象额外加 RAM 和失速
if truth
    CLram = p.k_ram / (1 + (h / p.h_ram)^2);
    CLtot = p.CLmax * tanh((CLw_lin + CLram) / p.CLmax);
    dCLnl = CLtot - CLw_lin - CLram;
end

% 5. 算平尾
eps_t   = (p.eps0 + p.eps_a * alpha) * kap_w;
alpha_t = alpha + p.it - eps_t + q * p.lt / V;
CLt     = at * (alpha_t - p.aL0t) + p.a_de * de;

% 6. 累加力和力矩
...

% 7. 输出
F = [L; D; M];
```

### 关键决定：`flag` 参数与 `is_truth` 字段

```matlab
truth = p.is_truth || strcmpi(flag, 'truth');
```

**两种判断方式并存的原因**：

- 调用方可能显式传 `'truth'`
- 也可能因为参数集本身是真实的（`p.is_truth = true`）而自动判定

**为什么不做成两个函数**：因为 90% 的代码是共享的（机翼、平尾、力矩累加），只有几行不同（RAM、失速）。**复制两份代码是维护灾难。**

### 输出为什么有两个

```matlab
function [F, aux] = wig_aero(x, p, flag)
```

- `F = [L; D; M]`：仿真需要的三个量
- `aux`：辅助量（地效因子、迎角、各分力），**只在需要时返回**

**为什么用 `if nargout > 1`**：

```matlab
if nargout > 1
    aux.qbar = qbar;
    ...
end
```

**为什么**：仿真主循环里每一步都调用这个函数，如果无条件构造 `aux` 结构体会拖慢速度。只在调试和绘图时才要它。

**这是一个重要的性能习惯**：热路径上不要做"反正也不贵"的事，因为它是每一步都要做的。

### 力矩的统一写法

```matlab
% 通用形式：M = z*Fx - x*Fz
Fx_w = Lw * sin(alpha) - Dw * cos(alpha);
Fz_w = -Lw * cos(alpha) - Dw * sin(alpha);
M_w  = p.z_acw * Fx_w - p.x_acw * Fz_w + qbar * p.S * p.c * p.Cmac;
```

**为什么每个力矩项都写成这个形式**：因为符号约定最容易错。用统一公式，只需要保证 `(x, z, Fx, Fz)` 填对，符号就不会错。

**对比**：如果每个力矩项都单独推导符号（"机翼抬头为正，平尾低头为负……"），几乎肯定会错一两处，而且很难查。

## 8.6 wig_dynamics.m：运动方程

### 结构

```matlab
function dx = wig_dynamics(x, ucmd, p, flag, gust)
% 1. 解包状态
V = max(x(1), 0.5);  gam = x(2);  alpha = x(3);
q = x(4);  h = x(5);  T = x(6);  de = x(7);

% 2. 执行器（限幅 + 速率限制）
de_c = wig_sat(ucmd(1), p.de_max);
dt_c = wig_sat(ucmd(2), 0.0, 1.0);
T_cmd = p.Tmin + dt_c * (p.Tmax - p.Tmin);
de_rate = wig_sat((de_c - de) / p.tau_e, p.de_rate);

% 3. 气动力（含阵风修正）
if ~isempty(gust) && any(gust ~= 0)
    ... 用相对气流重算 V、gamma、alpha ...
end
F = wig_aero(xa, p, flag);

% 4. 运动方程
Tx = T * cos(alpha + p.i_T);
Tz = T * sin(alpha + p.i_T);
Falong = Tx - D - p.m * p.g * sin(gam);
Fperp  = L + Tz - p.m * p.g * cos(gam);

dx(1) = Falong / p.m;              % dV/dt
dx(2) = Fperp / (p.m * V);         % dgamma/dt
dx(3) = q - dx(2);                 % dalpha/dt
dx(4) = M / p.Iyy;                 % dq/dt
dx(5) = V * sin(gam);              % dh/dt
dx(6) = (T_cmd - T) / p.tau_T;     % dT/dt
dx(7) = de_rate;                   % dde/dt
```

### 关键细节

**细节 1：`V = max(x(1), 0.5)`**

`dγ/dt = Fperp/(m·V)`，如果 V 趋近零会除零。虽然实际不会发生，但数值积分中可能出现瞬时小值。加个下限是**廉价的安全措施**。

**细节 2：`dx(3) = q - dx(2)`**

直接复用刚算出来的 `dx(2)`，而不是重算一遍 `Fperp/(m·V)`。**既快又保证一致。**

**细节 3：阵风修正放在气动计算之前**

```matlab
Vx = V*cos(gam) - gust(1);
Vz = V*sin(gam) - gust(2);
Va = sqrt(Vx^2 + Vz^2);
gam_a = atan2(Vz, Vx);
alpha_a = (gam + alpha) - gam_a;    % 用 theta 减去气流航迹角
```

**物理含义**：阵风改变了**相对气流**的方向和大小，所以气动力要按相对气流算，但运动方程仍按地面参考系写。

**`alpha_a = (gam + alpha) - gam_a` 这一行为什么这么写**：

- `gam + alpha` 就是俯仰角 θ（用恒等式）
- `gam_a` 是气流航迹角
- 所以 `alpha_a = θ - gam_a` √ 正是迎角的定义

**写成 `(gam + alpha)` 而不是新变量 θ，是为了强调"这里用的是 θ = γ + α 这个恒等式"。**

### 执行器的速率限制

```matlab
de_rate = wig_sat((de_c - de) / p.tau_e, p.de_rate);
```

**为什么要有速率限制**：真实舵机有最大转速。没有它，仿真会给出"舵瞬间到位"的假象。

**为什么用 `sat` 而不是分段**：`sat` 函数连续，数值积分更稳定。

## 8.7 wig_trim.m：配平

### 双求解器策略

```matlab
% 主求解器：fsolve
try
    [zsol, ~, exitflag] = fsolve(@(zz) trim_residual(zz, V, h, p, flag), z, opts);
    ok = (exitflag > 0);
catch
    ok = false;
end

% 回退：自研阻尼牛顿法
if ~ok
    [zsol, ok] = newton_trim(z, V, h, p, flag);
end
```

**为什么要回退**：`fsolve` 属于 Optimization Toolbox，不是所有 MATLAB 安装都有。**工程代码必须考虑"依赖不存在"的情况。**

**这是很实际的考虑**：如果别人拿到你的代码跑不起来，代码就没有价值。

### 残差的无量纲化

```matlab
W = p.m * p.g;
r = [ (F(1) + T*sin(alpha + p.i_T) - W) / W;      % 除以重量
      (T*cos(alpha + p.i_T) - F(2))        / W;
       F(3) / (W * p.c) ];                          % 力矩÷(重量×弦长)
```

**为什么除以 W 和 W·c**：让三个残差的**量级接近**。

如果不除：力的残差量级是 100 N，力矩的残差量级是 1 N·m。求解器看到"力误差 100"和"力矩误差 1"，会认为力误差严重得多，从而忽略力矩平衡。

**归一化后，三个残差都是无量纲的、量级约 1**，求解器才能公平对待。

**这是一个通用技巧**：任何数值求解问题，把不同量纲的量归一化到同一量级。

### 阻尼线搜索

```matlab
lam = 1.0;
for k = 1:30
    zn = z + lam*d;
    if norm(trim_residual(zn, ...)) < norm(r)
        break;      % 找到能减小残差的步长
    end
    lam = lam * 0.5;    % 否则减半步长
end
z = z + lam*d;
```

**为什么**：牛顿法算出的步长方向是对的，但**大小可能过大**。线搜索保证每一步都真的让残差下降，避免发散。

**这是非线性求解的标准做法**，不是可选项。

## 8.8 wig_rbf_init.m：网络结构

```matlab
function nn = wig_rbf_init(p)
% 力矩通道：输入 [alpha, q, h]，5x3x5 = 75 节点
rng1 = [p.ctrl.nn.c1_a(:)'; p.ctrl.nn.c1_q(:)'; p.ctrl.nn.c1_h(:)'];
n1   = p.ctrl.nn.n1(:)';
nn.C1   = grid_centers(n1);      % 3 x 75
nn.sig1 = grid_sigma(n1);        % 3 x 1
nn.N1   = size(nn.C1, 2);
...
```

### 中心为什么用矩阵存

`nn.C1` 是 3×75 的矩阵，每一列是一个中心点。

**为什么这么存**：因为求基函数时要算"输入到所有中心的距离"：

```matlab
d2 = zeros(1, N);
for i = 1:3
    d2 = d2 + ((z(i) - C(i,:)) ./ sig(i)).^2;
end
phi = exp(-0.5 * d2);
```

`C(i,:)` 是第 i 维的所有中心，一次就能算 75 个距离。**这是 MATLAB 的向量化写法**，比循环 75 次快得多。

**为什么不用 `pdist` 或 `bsxfun`**：因为要保证代码能在**代码生成**（MATLAB Coder）环境下工作，那些函数不一定支持。用基本的算术运算最保险。

### 宽度为什么取网格间距

```matlab
function s = grid_sigma(n)
for i = 1:3
    if n(i) > 1
        s(i) = 2/(n(i) - 1);    % 归一化区间长度 2 除以间隔数
    else
        s(i) = 1.0;
    end
end
```

以 5 个中心为例：归一化区间是 [-1, 1]，长度 2，4 个间隔，所以间距 = 0.5。

**为什么宽度 = 间距**：这样相邻基函数在中心处的值是 `exp(-0.5) ≈ 0.61`，重叠适中。

- 宽度太大 -> 所有基函数都差不多，网络分辨不出细节
- 宽度太小 -> 基函数之间有空隙，网络在空隙处输出接近零

## 8.9 wig_ctrl_update.m：控制器核心（逐段讲解）

这是最重要的文件。我们用"输入-处理-输出"的顺序讲。

### 函数签名

```matlab
function [u, ctrl, dbg] = wig_ctrl_update(xm, ref, ctrl, p)
```

**三个输出**：

- `u`：控制量 `[δ_e指令; 油门指令]`
- `ctrl`：更新后的控制器内部状态
- `dbg`：调试量（误差、中间指令、网络输出……）

**为什么控制器状态要显式传入传出，而不是用 `persistent`**：

| 做法 | 优点 | 缺点 |
|---|---|---|
| `persistent` 变量 | 调用简单 | **无法查看内部状态**；无法在多个实例间切换；Simulink 里不好用 |
| **显式传递** | **纯函数、可测试、可复用、Simulink 可用** | 调用时要多传一个参数 |

**这个选择决定了同一份代码能同时用于脚本仿真和 Simulink 的 S-Function**，是后面"两种仿真途径结果一致"的前提。

### 第 0 段：量测滤波

```matlab
if isempty(ctrl.xf)
    ctrl.xf = xm([1 3 4 5]);       % 首次调用：用当前值初始化
end
tau_f = max(p.sens.tau_f, 1e-4);
ctrl.xf = ctrl.xf + (Ts_/tau_f) * (xm([1 3 4 5]) - ctrl.xf);
Vf = ctrl.xf(1);  alf = ctrl.xf(2);  qf = ctrl.xf(3);  hf = ctrl.xf(4);
```

**为什么要有这层滤波**：传感器有噪声，直接拿噪声去算控制量会导致舵机抖动。

**`max(p.sens.tau_f, 1e-4)` 的作用**：防止 `tau_f = 0` 导致除零。如果 `tau_f` 太小（比如 1e-4 而 Ts = 0.005），`Ts/tau_f = 50 > 2`，这个欧拉积分会**发散**。这是一个必须注意的数值问题。

**教训：用欧拉法实现一阶滤波器时，必须满足 `Ts/τ < 2`。**

### 第 1 段：RBF 网络求值

```matlab
z1   = wig_norm([alf; qf; hf], ctrl.nn.rng1);       % 归一化
ph1r = wig_rbf_phi(z1, ctrl.nn.C1, ctrl.nn.sig1);   % 基函数
phi1 = ph1r * (qbar * p.S * p.c / p.Iyy);           % 加权（量纲处理）
uM   = ctrl.W1' * phi1;                              % 网络输出
```

**这一段的三个步骤对应第 7 章的三个推导**：

1. `wig_norm`：归一化到 [-1,1]（第 7.7 节）
2. `wig_rbf_phi`：算 `φj(z)`（第 7.7 节的公式）
3. 乘 `q∞Sc/I_yy`：量纲处理（第 7.7 节的"回归向量缩放"）

**`ctrl.W1' * phi1` 为什么是转置乘**：

- `W1` 是 N×1 列向量
- `phi1` 也是 N×1 列向量
- `W1' * phi1` 得到标量（内积）= `Σ W1j·φ1j` √

**如果写成 `W1 * phi1'` 会得到 N×N 矩阵** —— 这是 MATLAB 里最常见的错误之一。

### 第 2 段：高度外环

```matlab
e_h    = hf - h_c;
hd_act = Vf * sin(gam);                             % 高度率：不用数值微分
arg    = (hd_c - p.ctrl.k_h * e_h - p.ctrl.k_hd * (hd_act - hd_c)) / max(Vf, 3.0);
gam_d  = asin(wig_sat(arg, sin(p.ctrl.gam_max)));
gam_dot_c = (wig_sat(gam_d, p.ctrl.gam_max) - ctrl.gam_c) / p.ctrl.tau_g;
```

**逐个说明为什么这么写**：

| 代码 | 对应公式 | 为什么 |
|---|---|---|
| `hd_act = Vf * sin(gam)` | `dh/dt = V·sinγ` | **直接用状态合成，不用数值微分**（微分会放大噪声） |
| `max(Vf, 3.0)` | 防止除零 | 速度极低时 γ 指令会爆掉 |
| `wig_sat(arg, sin(gam_max))` | 限幅 | `arcsin` 的参数必须 ≤ 1，且实际不允许大航迹角 |
| 除以 `p.ctrl.tau_g` | 一阶滤波器 | 这就是 `dγ_c/dt`，**不需要解析求导** |

### 第 3 段：姿态内环

```matlab
e_th = theta - ctrl.th_c;
theta_d  = wig_sat(ctrl.gam_c + alf, p.ctrl.th_max);   % 恒等式 + 限幅
th_dot_c = (wig_sat(theta_d, 0.80) - ctrl.th_c) / p.ctrl.tau_th;

q_d  = th_dot_c - p.ctrl.k_th * e_th;
e_q  = qf - ctrl.q_cf;
q_dot_cf = (wig_sat(q_d, 6.0) - ctrl.q_cf) / p.ctrl.tau_q;

nu = q_dot_cf - p.ctrl.k_q * e_q;
```

**关键点 1：`theta = gam + alf`（用滤波后的迎角）**

代码开头有这么一行：

```matlab
theta = gam + alf;      % 与指令通道保持一致，使用滤波后迎角合成俯仰角
```

**为什么要用滤波后的 α 而不是原始 α**：

因为指令 `theta_d = gam_c + alf` 用的也是滤波后的 α。如果误差 `e_th = theta - th_c` 用原始 α，指令用滤波 α，两者之间会有一个"滤波滞后"的虚假误差，形成不必要的反馈路径。

**保持一致是这里的关键原则。**

**关键点 2：两次 DSC 滤波**

- 第一次：`θ_d` -> `θ_c`，时间常数 `tau_th`
- 第二次：`q_d` -> `q_cf`，时间常数 `tau_q`

**为什么要两次**：因为反步法每一级都需要上一级虚拟控制量的导数，两次滤波提供了两个导数（`th_dot_c` 和 `q_dot_cf`）。

**关键点 3：滤波顺序**

```matlab
q_dot_cf = (sat(q_d) - ctrl.q_cf) / tau_q;    % 先算导数（用当前的 q_cf）
nu = q_dot_cf - k_q * e_q;                     % 用导数算控制量
...
ctrl.q_cf = ctrl.q_cf + Ts_ * q_dot_cf;        % 最后才更新滤波器状态
```

**为什么这个顺序**：控制量必须用**当前时刻**的滤波器状态算，更新要放在最后。如果顺序错了，控制就用了"未来"的信息，因果关系被破坏。

### 第 4 段：动态逆

```matlab
xtmp = [V; gam; alpha; q; h; T; 0];        % 舵偏置零
Fnom = wig_aero(xtmp, p, 'nominal');       % 用名义模型算
Mn0  = Fnom(3);                            % 零舵偏力矩
f0   = Mn0 / p.Iyy;

kap_w   = wig_ge(h, p.b, p);
eps_t   = (p.eps0 + p.eps_a * alpha) * kap_w;
alpha_t = alpha + p.it - eps_t + q * p.lt / max(V, 0.5);
qt      = qbar * p.eta_t;
Mde     = -(p.lt*cos(alpha_t) + p.dz_t*sin(alpha_t)) * qt * p.St * p.a_de;
b       = Mde / p.Iyy;
```

**关键点 1：`xtmp` 里舵偏置零**

因为我们要的是 `M0(x)`（零舵偏力矩），舵偏的贡献由 `b·δ_e` 单独处理。**这就是第 7.6 节的模型分解。**

**关键点 2：`Mde` 是解析求出的，不是数值差分**

```
M_δe = ∂M/∂δ_e = -(l_t·cos α_t + Δz_t·sin α_t) · q_t · S_t · a_δe
```

这个表达式是从第 3 章的力矩公式对 `δ_e` 求导得来的：

- `C_Lt = ... + a_δe·δ_e`
- `M_t = -Δz_t·F_x,t + l_t·F_z,t`
- 对 `δ_e` 求导：`∂F_x,t/∂δ_e = q_t·S_t·a_δe·sin α_t`，`∂F_z,t/∂δ_e = -q_t·S_t·a_δe·cos α_t`
- 代入得 `M_δe = -(l_t·cos α_t + Δz_t·sin α_t)·q_t·S_t·a_δe`

**为什么这里用解析式而不是数值差分**：因为这个量在控制器里每一步都要算，数值差分要调用 2 次 `wig_aero`，太慢。而它的解析式很简单。

**关键点 3：`b` 的数值保护**

```matlab
if abs(b) < 1e-8
    b = -1e-8;      % 防止除零
end
```

`δ_e = (ν - ...)/b`。如果 `b` 接近零（速度极低时），控制量会爆掉。**这是必要的保护。**

### 第 5 段：鲁棒项与控制律

```matlab
if p.ctrl.enable_rob
    ur = p.ctrl.eta_r * tanh(e_q / p.ctrl.Phi_r);
else
    ur = 0;
end

de_unsat = (nu - f0 - uM - ur) / b;
de_cmd   = wig_sat(de_unsat, p.de_max);
sat_e    = abs(de_unsat) >= p.de_max;      % 记录是否饱和
```

**`sat_e` 这个标志位的作用**：后面要用它决定"要不要继续学习"（见第 6 段）。

### 第 6 段：速度回路与自适应律

```matlab
e_V = Vf - V_c;
IV_new = wig_sat(ctrl.IV + Ts_ * e_V, p.ctrl.IV_max);
dV_des = Vd_c - p.ctrl.k_V * e_V - p.ctrl.k_IV * IV_new;

urV = p.ctrl.eta_V * tanh(e_V / p.ctrl.Phi_V);

ca = cos(alpha + p.i_T);
if abs(ca) < 0.2, ca = sign(ca) * 0.2; end

gff = p.m * p.g * sin(ctrl.gam_c);      % ★ 用指令航迹角，不是量测值
T_cmd = (p.m * (dV_des + uD - urV) + Dnom + gff) / ca;
```

**三个关键点**：

**关键点 1：`- urV` 是减号**

第 7.9 节讲过，鲁棒项必须以减号进入，才能让误差动态里出现 `-u_rV`。**写成加号就是正反馈。**（第 9 章的第一个坑）

**关键点 2：`gff` 用 `ctrl.gam_c` 而不是 `gam`**

用实测 γ 会形成正反馈回路。（第 9 章的第四个坑）

**关键点 3：`ca` 的保护**

`ca = cos(α + i_T)`，如果迎角接近 90° 会趋零。加一个下限保护。

### 第 7 段：自适应律

```matlab
nu_e = p.ctrl.nn.nu_e;
if p.ctrl.enable_nn
    if ~sat_e                                       % ★ 舵饱和时冻结学习
        tau1 = p.ctrl.nn.Gam1 * (phi1 * e_q - nu_e * abs(e_q) * ctrl.W1);
        ctrl.W1 = wig_proj(ctrl.W1, tau1, p.ctrl.nn.Wmax, Ts_);
    end
    if ~sat_t                                       % 油门饱和时冻结
        tau2 = -p.ctrl.nn.Gam2 * (phi2 * e_V + nu_e * abs(e_V) * ctrl.W2);
        ctrl.W2 = wig_proj(ctrl.W2, tau2, p.ctrl.nn.Wmax, Ts_);
    end
end
```

**关键点 1：两个通道的符号相反**

```matlab
tau1 = +Gam1 * (phi1 * e_q - ...);      % 力矩通道：正号
tau2 = -Gam2 * (phi2 * e_V + ...);      % 阻力通道：负号
```

**这是第 7.8 节推导的直接结果**，代码里专门写了注释解释原因。

**关键点 2：饱和时冻结学习**

**为什么**：如果舵已经打到限幅（比如 ±25°），那么误差 `e_q` 已经**不是控制器的责任**了——是执行器能力不够。这时候如果继续学习，网络会把"执行器饱和"误认为是"模型失配"，学出错误的东西。

**这叫抗积分饱和（anti-windup）**，是工程控制的必备技巧。

**关键点 3：`wig_proj` 里包含了欧拉积分**

```matlab
function [W, Wd] = wig_proj(W, tau, Wmax, Ts)
Wd = wig_proj_op(W, tau, Wmax);     % 先做投影
W  = W + Ts * Wd;                    % 再欧拉积分
n = norm(W);
if n > Wmax * 1.001                 % 数值安全网
    W = W * (Wmax / n);
end
```

**为什么把积分也放进来**：调用方只需要写一行，不容易漏掉积分或投影。

**为什么要那个 1.001 的收缩**：投影算子理论上保证有界，但浮点误差可能让范数略微超界。加一个几乎不会触发的安全网。

## 8.10 wig_simulate.m：仿真引擎

### 核心循环结构

```matlab
for k = 1:Nt
    t = tvec(k);

    % 1. 参考指令二阶滤波
    zh = zh + dt * [zh(2); wn_h^2*(ref_h(k) - zh(1)) - 2*wn_h*zh(2)];

    % 2. 控制器采样（零阶保持）
    if t >= next_u - 1e-12
        [u, ctrl, dbg] = wig_ctrl_update(xm, ref, ctrl, pc);
        next_u = next_u + Ts;
    end

    % 3. 记录
    X(k,:) = x';

    % 4. RK4 积分被控对象
    k1 = wig_dynamics(x, u, pt, plant, g);
    k2 = wig_dynamics(x + 0.5*dt*k1, u, pt, plant, g);
    k3 = wig_dynamics(x + 0.5*dt*k2, u, pt, plant, g);
    k4 = wig_dynamics(x + dt*k3, u, pt, plant, g);
    x = x + (dt/6)*(k1 + 2*k2 + 2*k3 + k4);
end
```

**为什么要用零阶保持**：

真实飞控计算机是**每 5 ms 算一次，然后保持这个控制量 5 ms**。所以：

```matlab
if t >= next_u - 1e-12        % 到了采样时刻
    ...控制器算一次...
    next_u = next_u + Ts;      % 下次采样时刻
end
% 两次采样之间，u 保持不变（零阶保持）
```

**这个细节很重要**：如果每个积分步都调用控制器（相当于 1000 Hz 控制器），性能会明显变好，但那是**假的**——真实计算机做不到。

**`- 1e-12` 的作用**：浮点数累加误差。`0.005 × 20` 可能不严格等于 `0.1`，加个极小量避免漏采样。

### 参考指令的二阶滤波器

```matlab
zh = zh + dt * [zh(2); wn_h^2*(ref_h(k) - zh(1)) - 2*wn_h*zh(2)];
```

**为什么不用阶跃直接给指令**：

阶跃指令会导致：
1. 控制器输出突变（微分项会给出无穷大）
2. 执行器瞬间饱和
3. 结构受冲击

**用二阶滤波器（相当于一个质量-弹簧-阻尼系统）**：

```
z1'' + 2ζω·z1' + ω²·z1 = ω²·目标值
```

- `ω_n`：带宽，决定指令响应快慢
- `ζ = 1`：临界阻尼，无超调

**这样同时得到指令值、一阶导、二阶导**（`zh(1)` 和 `zh(2)`），控制器前馈需要它们。

**机械类比**：这就是一个"指令平滑器"，像汽车油门的电子节气门，避免猛踩猛松。

## 8.11 几个 MATLAB 编程要点

### 要点 1：预分配数组

```matlab
X = zeros(Nt, nx);      % 预先分配
for k = 1:Nt
    X(k,:) = x';
end
```

**为什么不直接 `X(end+1,:) = x'`**：那样 MATLAB 每次都要重新分配内存并复制。对于 40000 步的仿真，差别是几十倍的速度。

### 要点 2：向量化

```matlab
d2 = zeros(1, N);
for i = 1:3
    d2 = d2 + ((z(i) - C(i,:)) ./ sig(i)).^2;    % 一次算 75 个
end
```

**为什么不用双重循环**：MATLAB 对向量运算有优化，向量化后快 10~100 倍。

### 要点 3：`wig_sat` 而不是 `min(max(...))`

```matlab
function y = wig_sat(u, lo, hi)
if nargin < 3
    hi = lo;
    lo = -hi;          % 支持对称限幅：wig_sat(x, 0.5) => [-0.5, 0.5]
end
y = min(max(u, lo), hi);
```

**为什么要封装**：因为限幅在代码里出现十几次。封装后：

- 语义清晰（读代码时一眼看出是限幅）
- 支持对称和非对称两种用法
- 将来要改成平滑限幅（比如 tanh）只改一处

### 要点 4：UTF-8 日志

```matlab
fid = fopen(logfile, 'w', 'n', 'UTF-8');
fprintf(fid, '%s', s);
fclose(fid);
```

**为什么不用 MATLAB 的 `diary`**：`diary` 使用系统默认编码（中文 Windows 上是 GBK），在 PowerShell 里读会乱码。

**显式指定 UTF-8** 保证日志在任何环境下都能正确阅读。

### 要点 5：异常也要保留输出

```matlab
cmd = sprintf(['try\n' ...
               '    %s;\n' ...
               'catch ME\n' ...
               '    disp(getReport(ME));\n' ...
               'end\n'], fcnName);
s = evalc(cmd);
```

**为什么这样写**：`evalc` 在函数抛异常时**不会返回已产生的输出**，调试时会丢掉所有线索（本工程就吃过这个亏）。把 `try/catch` 放进 `evalc` 内部，就能保住报错前的全部输出。

## 8.12 本章小结

- **一个文件 = 一个物理概念**，这样能单独测试、快速定位问题。
- **参数与逻辑分离**，派生量当场计算。
- 气动函数用 `[F, aux]` 双输出 + `nargout` 判断，兼顾速度与调试。
- 力矩统一用 `M = z·Fx - x·Fz`，避免符号错误。
- 控制器状态**显式传入传出**，这让同一份代码能用于 Simulink。
- 仿真引擎用**固定步长 RK4 + 200 Hz 零阶保持控制器**，模拟真实数字飞控。
- 参考指令用**二阶滤波器**平滑，同时提供一二阶导数。
- 自适应律里**两个通道符号相反**，**饱和时冻结学习**。
- 一阶滤波器的欧拉实现必须满足 **`Ts/τ < 2`**。
