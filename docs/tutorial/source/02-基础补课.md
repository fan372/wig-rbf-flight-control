# 第 2 章 基础补课

这一章把后面要用到的概念全部补一遍。**已经会的可以跳过，但建议扫一眼**，因为我用的记号和约定可能和你当年学的不完全一样。

## 2.1 坐标系：为什么需要两个

要描述一架飞机的运动，第一件事是**规定从哪儿看**。

### 地面坐标系（惯性系）

固定在地面上，x 轴指向前方，z 轴指向上方。飞机的**高度 h** 就是在这个坐标系里量的。

### 机体坐标系

固定在飞机上，跟着飞机一起转：

- x 轴：从机尾指向机头（叫"机体纵轴"）
- y 轴：指向右翼
- z 轴：指向机腹（**注意：指向下**）

为什么 z 轴朝下？这是航空界的传统约定，原因很实际：飞机在平飞时重力沿 +z 方向，写方程时符号好记。

### 为什么要分开

因为**不同的物理量在不同的坐标系里最自然**：

| 物理量 | 在哪个系里最自然 | 原因 |
|---|---|---|
| 高度 h | 地面系 | 地面不会动 |
| 升力 L、阻力 D | 气流方向 | 升力永远垂直于气流，阻力永远平行于气流 |
| 俯仰力矩 M | 机体系 | 飞机绕自己的横轴转 |

**关键的翻译关系**：机体坐标系的 x 轴（机头方向）和气流方向之间差一个角度，这个角度就是**迎角 α**。

## 2.2 三个角度：迎角、俯仰角、航迹倾角

这是初学者最容易搞混的地方。用一张图来理解：

```
              水平线（地面参考）
                 |
   机头指向 -----+------  俯仰角 θ：机头相对水平线的夹角
                 |
   气流方向 ----+        航迹倾角 γ：飞机实际往哪飞，相对水平线
                 |
   机翼弦线 ---+          迎角 α：机翼弦线相对气流的夹角
```

三者的关系是一个**恒等式**（不是近似，是定义）：

```
θ = γ + α
```

用大白话讲：

- **俯仰角 θ**：飞机**姿态**（机头指哪儿）
- **航迹倾角 γ**：飞机**实际运动方向**（往哪儿飞）
- **迎角 α**：机翼**相对气流的迎风角度**（决定产生多少升力）

打个比方，这就像开车：

- θ 是**车头朝向**
- γ 是**实际行驶方向**
- α 是**侧风相对于车头的角度**

如果车在笔直前进（γ = 0）但方向盘打着（θ = 5 度），那车身和运动方向就有夹角——飞机上对应的就是迎角 α = θ - γ = 5 度。

**为什么这个恒等式重要**：第 7 章会看到，控制器里有一行 `θ_c = γ_c + α`，它的正确性完全依赖这个恒等式。搞懂这一条，那一行代码就懂了。

### 另外一个关键关系

高度变化率和航迹倾角的关系：

```
dh/dt = V · sin(γ)
```

意思很直白：**往上飞的速率 = 速度 × 爬升角的正弦**。这和"斜坡上汽车的高度变化率 = 车速 × sin(坡度)"是同一件事。

## 2.3 四个力

飞机在纵向平面内受四个力。

### 升力 L

垂直于气流方向，向上。来源是机翼上下表面的压力差。

工程上把它写成**无量纲系数**的形式（这是航空界的惯例，因为这样可以跨尺寸对比）：

```
L = q · S · C_L
```

其中：

- `q = 0.5 · ρ · V²`，叫**动压**，单位是帕斯卡（Pa），代表"气流冲击强度"。ρ 是空气密度（海平面约 1.225 kg/m³）
- `S` 是机翼面积（m²）
- `C_L` 是**升力系数**，无量纲

`C_L` 怎么来？在小迎角范围内，它和迎角成线性关系：

```
C_L = a · (α - α_L0)
```

- `a` 叫**升力线斜率**，单位是 1/弧度（每增加 1 弧度迎角，升力系数增加多少）
- `α_L0` 叫**零升迎角**，是"升力为零时的迎角"。因为机翼通常有弯度，所以这个角是负的（约 -3 度）

**物理直觉**：迎角越大，气流被偏折得越厉害，升力越大。但迎角大到一定程度（约 15 度）气流会分离，升力突然掉下来——这就是**失速**。

### 阻力 D

平行于气流，向后。分两部分：

```
D = q · S · (C_D0 + C_Di)
```

- `C_D0`：**废阻力系数**，来自摩擦、形状、支架等，和升力无关
- `C_Di`：**诱导阻力系数**，和升力的平方成正比

**诱导阻力是什么？** 这是初学者最困惑的概念，我们花点篇幅讲清楚。

机翼产生升力的原理是"把气流向下偏折"。但机翼是有限长的，翼尖处的空气会从高压的下表面绕到低压的上表面，形成**翼尖涡**。这两个涡在机翼后面拖出两条长长的尾迹，它们在机翼处产生一个**向下的速度分量**（叫**下洗**）。

机翼本来感觉自己迎角是 α，但因为有下洗，实际感受到的有效迎角变小了。要产生同样的升力，就得把机头再抬高一点——而抬高机头就意味着升力的方向往后偏了一点，产生一个额外的阻力分量。

这就是**诱导阻力**：

```
C_Di = C_L² / (π · AR · e)
```

- `AR`：**展弦比** = 翼展² / 机翼面积。翼展越长越细，翼尖涡相对影响越小，诱导阻力越小（这就是滑翔机翼展特别长的原因）
- `e`：**奥斯瓦尔德效率因子**，约 0.8~0.9，用来修正"机翼不是理想椭圆分布"带来的损失

**记住一句话**：诱导阻力来自翼尖涡，翼尖涡来自有限翼展。而地面效应**正好能削弱翼尖涡**——这就是地效飞行器省油的物理本质。

### 推力 T

由发动机产生，沿推力线方向。本工程最大 35 N。

### 重力 mg

永远竖直向下，12 kg × 9.8 m/s² = 117.7 N。

## 2.4 牛顿第二定律在"运动坐标系"里怎么写

这是本章最重要的一节。

你本科学的是：**F = ma**。在静止坐标系里，a = dv/dt，没什么花样。

但现在我们要在**跟着飞机转动的坐标系**里写方程，这里有个关键区别：**物体沿曲线运动时，加速度有两个分量**。

### 切向（沿航迹方向）

飞机沿航迹方向加速或减速，加速度就是速度的变化率 dV/dt：

```
m · dV/dt = T·cos(α + i_T) - D - m·g·sin(γ)
```

右边三项分别是：

- 推力的沿航迹分量（推力线可能有个安装角 i_T）
- 阻力（向后，减速）
- 重力的沿航迹分量（爬升时重力拖后腿，减速）

### 法向（垂直航迹方向）

**这里是关键**：飞机沿曲线飞行时，即使速度大小不变，速度的**方向**在变，所以有加速度。这个加速度叫**向心加速度**，大小是：

```
a_向心 = V · (dγ/dt)
```

（你可能记得向心加速度 = V²/R，其中 R 是转弯半径。因为 R = V/(dγ/dt)，代入就得到 V·dγ/dt）

所以法向方程是：

```
m · V · dγ/dt = L + T·sin(α + i_T) - m·g·cos(γ)
```

**机械类比**：这就是"汽车过拱桥"的方程。桥顶时重力向下、支持力向上，两者之差提供向心力。飞机爬升时，"桥面"就是弯曲的航迹。

### 旋转方程

绕横轴的转动，和你在理论力学里学的刚体转动完全一样：

```
I_yy · dq/dt = M
```

- `I_yy`：绕横轴的转动惯量（kg·m²），本对象是 1.15
- `q`：俯仰角速度（rad/s），dθ/dt = q
- `M`：俯仰力矩（N·m）

**类比**：这就是 `J·θ'' = M`，和转子动力学里的转动方程一模一样。

## 2.5 微分方程与状态变量

把上面几个方程合起来，我们得到一组**联立一阶微分方程**：

```
dV/dt     = f1(V, γ, α, q, h, T, δe)
dγ/dt     = f2(...)
dα/dt     = f3(...)
dq/dt     = f4(...)
dh/dt     = f5(...)
dT/dt     = f6(...)
dδe/dt    = f7(...)
```

括号里那串 `(V, γ, α, q, h, T, δe)` 就是**状态变量**——它们是"描述系统当前情况所需的最小信息集合"。

**为什么叫"状态"**：只要知道这 7 个数在某一时刻的值，再加上从这一刻起的控制输入，未来所有时刻的行为就唯一确定了。就像刚体运动只要知道位置和速度，后续轨迹就定了。

**为什么要把所有方程写成一阶**：因为数值积分算法（我们用的是龙格-库塔法）的标准输入格式就是"一阶微分方程组"。把高阶方程降成一阶是标准操作：

```
d²θ/dt² = M/I    →    令 q = dθ/dt
                      则 dq/dt = M/I
```

这样就把一个二阶方程变成了两个一阶方程。

**代码对应**：`wig_dynamics.m` 就是把这 7 个 `d?/dt` 算出来放进一个 7×1 的列向量返回。

## 2.6 线性化：把非线性问题变成线性问题

我们的方程里有 `sin(γ)`、`α·V²` 这类非线性项，没法直接用线性控制理论。怎么办？**在工作点附近做泰勒展开，只保留一次项。**

### 泰勒展开复习

对一元函数 f(x)，在 x0 附近：

```
f(x) ≈ f(x0) + f'(x0)·(x - x0) + (高阶项)
```

**物理含义**：任何光滑曲线，在足够小的范围里看起来都像直线。斜面的斜率就是导数。

### 推广到多元

对 `f(x1, x2, ..., xn)`：

```
f(x) ≈ f(x0) + Σi [∂f/∂xi |x0] · (xi - xi0)
```

那些偏导数排成一个矩阵，就是**雅可比矩阵**：

```
A = [ ∂f1/∂x1  ∂f1/∂x2  ... ]
    [ ∂f2/∂x1  ∂f2/∂x2  ... ]
    [ ...                   ]
```

于是非线性方程 `dx/dt = f(x, u)` 变成线性方程：

```
d(Δx)/dt = A · Δx + B · Δu
```

其中 `Δx = x - x0` 是**小偏差**，`B = ∂f/∂u` 是输入矩阵。

**工程含义**：`A` 矩阵描述"飞机本身的性质"，`B` 矩阵描述"舵面有多大的操纵能力"。这两个矩阵是后面所有分析的出发点。

**代码对应**：`wig_linearize.m` 用**中心差分**算这些偏导数——不去推导解析公式，而是直接数值求：

```
∂f/∂xi ≈ [f(x + Δxi) - f(x - Δxi)] / (2Δxi)
```

为什么要数值求？因为解析推导太容易出错，而且模型一改就得重推。数值差分虽然慢一点，但永远不会"推错"。

## 2.7 特征值与模态

### 特征值是什么

对一个方阵 `A`，如果存在非零向量 `v` 和数 `λ` 使得：

```
A·v = λ·v
```

那么 `λ` 叫**特征值**，`v` 叫**特征向量**。

**物理含义**（这一条比定义重要得多）：

> 特征值 `λ` 告诉你系统某个"固有运动模式"的**衰减快慢**和**振荡频率**；
> 特征向量 `v` 告诉你这个模式里**哪些状态在动、动的比例是多少**。

### 复特征值怎么读

特征值通常是复数：`λ = σ + jω`

- **实部 σ**：衰减率。**σ < 0 稳定**（指数衰减），**σ > 0 发散**（指数增长）
- **虚部 ω**：振荡频率（rad/s）
- 对应的时间常数 = `1/|σ|`（只和实部有关）

再定义两个常用量：

- **固有频率** `ω_n = |λ| = √(σ² + ω²)`：振荡快慢
- **阻尼比** `ζ = -σ/ω_n`：振荡衰减程度
  - `ζ > 1`：过阻尼，不振荡，慢慢回到平衡
  - `0 < ζ < 1`：欠阻尼，振荡着衰减
  - `ζ = 0`：等幅振荡（临界）
  - **`ζ < 0`：振荡着发散**

### 机械类比

这和你做振动实验时的单自由度系统完全对应：

```
m·x'' + c·x' + k·x = 0
```

特征方程 `m·λ² + c·λ + k = 0`，解出来的 λ 就是特征值。

- `c` 是阻尼（对应 σ：阻尼越大衰减越快）
- `k` 是刚度（对应 ω：刚度越大振得越快）
- 如果阻尼是**负的**（比如干摩擦引起的自激振动），系统就会**自激发散**——这就是 `ζ < 0` 的情况

**地效飞行器的问题就是：地面效应给浮沉模态加了一个"负阻尼"。**

### 飞机的纵向模态

飞机纵向有几种典型模态，名字很形象：

| 模态 | 周期 | 特征 | 物理图像 |
|---|---|---|---|
| 短周期 | 1~3 秒 | 迎角快速变化，速度几乎不变 | 机头上下点头 |
| 浮沉 | 5~15 秒 | 速度与高度交换，迎角几乎不变 | 像海豚一样起伏 |
| 高度 | 更慢 | 高度缓慢漂移 | 整体升沉 |

**为什么短周期和浮沉能分开**：因为它们的**时间尺度差很多**（1 秒 vs 10 秒）。数学上这叫"时间尺度分离"，工程上可以分别处理——这也是我们控制器分内外环的依据。

## 2.8 传递函数、带宽、相位裕度

### 传递函数

对线性系统，输入和输出的拉普拉斯变换之比就是**传递函数**。比如一阶惯性环节：

```
G(s) = 1 / (τ·s + 1)
```

- `τ` 是**时间常数**：输入突变后，输出大约经过 3τ 到达新稳态的 95%
- **舵机的动态**就是一个一阶惯性环节，本工程舵机时间常数 τ_e = 0.05 秒

### 带宽

**带宽**是"系统能跟得上多快的输入"。粗略地说，带宽（rad/s）约等于 `1/τ`。

本工程各回路的带宽：

- 舵机：1/0.05 = 20 rad/s
- 俯仰角速度内环：约 6 rad/s
- 俯仰角中环：约 3 rad/s
- 高度外环：约 2 rad/s

**串级控制的基本原则**：**内环带宽必须远高于外环**（至少 3~5 倍）。否则外环设计时"假设内环瞬间跟得上"就不成立，整个设计会崩。

### 相位裕度

反馈控制里最重要的安全指标。**相位裕度**是"系统开环频率响应的相位距离 -180° 还有多少度"。

- 相位裕度 > 45°：安全
- 相位裕度 30°~ 45°：勉强
- 相位裕度 < 30°：振荡甚至发散

**为什么**：负反馈靠"反相"工作。如果因为延迟，信号在闭环绕一圈后相位已经翻了 180°，负反馈就变成了**正反馈**——这就是自激发散。

**教训**：**滞后环节（延迟）是控制回路的天敌**。本工程第 9 章会看到，好几个坑都是滞后引起的。

## 2.9 什么是"稳定"

控制系统里"稳定"有好几个层次，本工程都会用到：

| 名称 | 含义 | 判据 |
|---|---|---|
| 李雅普诺夫意义下稳定 | 初始偏差不会越来越大 | 有界 |
| **渐近稳定** | 偏差最终收敛到零 | 特征值实部全负 |
| **一致最终有界（UUB）** | 偏差收敛到某个小球内 | 本工程的目标 |
| 输入输出稳定 | 有界输入产生有界输出 | |

**为什么本工程只能做到 UUB 而不是渐近稳定**：

因为我们用了神经网络去"逼近"未知函数。而神经网络**永远只能逼近，不能精确等于**——总有一个残差 ε。只要 ε ≠ 0，误差就不可能收敛到零，只能收敛到一个和 ε 成比例的小球里。

但这已经足够工程使用了：**只要那个小球比允许误差小就行**。

## 2.10 本章小结

- 需要**两个坐标系**：地面系量高度，机体系写力矩。迎角 α 就是两者的"翻译角度"。
- 三个角度的恒等式 `θ = γ + α` 是后面控制器结构的基础。
- 升力 `L = q·S·C_L`，诱导阻力 `C_Di = C_L²/(π·ARe)`，都写成无量纲系数形式。
- **曲线运动有法向加速度** `V·dγ/dt`，这是纵向运动方程里最容易漏的一项。
- 把高阶方程降成一阶方程组，状态变量是"描述系统的最小信息集合"。
- **线性化 = 泰勒展开取一次项**，得到的 A、B 矩阵是控制设计的出发点。
- **特征值的实部决定稳定、虚部决定振荡**；阻尼比 ζ < 0 就是自激发散。
- **相位裕度**衡量安全余量，而**滞后是相位裕度的杀手**。
