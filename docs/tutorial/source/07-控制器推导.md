# 第 7 章 控制器从零推导

这一章把第 6 章选定的方案，一步步推导成可以写进代码的公式。**每一个式子都会说明它从哪来。**

## 7.1 整体思路：把大问题拆成四个小问题

我们要控制的量有两个：**高度 h** 和**速度 V**。可用的手段有两个：**升降舵 δ_e** 和**油门 δ_t**。

关键观察：

| 手段 | 主要影响 | 次要影响 |
|---|---|---|
| 升降舵 | 俯仰姿态 -> 航迹角 -> **高度** | 速度（通过航迹角变化间接影响） |
| 油门 | 推力 -> **速度** | 高度（通过速度影响升力） |

所以可以近似解耦：

- **用升降舵管高度**（通过俯仰姿态）
- **用油门管速度**

于是问题拆成两条链：

```
链 1（高度）：h -> γ -> θ -> q -> δ_e
链 2（速度）：V -> δ_t
```

**链 1 有四级，这就是反步法要处理的结构。**

## 7.2 第一步：定义误差

每一级定义"我想去哪"和"我在哪"的差：

| 误差 | 定义 | 含义 |
|---|---|---|
| `e_h` | `h - h_c` | 高度误差（c 下标表示 command，指令） |
| `e_θ` | `θ - θ_c` | 俯仰角误差 |
| `e_q` | `q - q_cf` | 角速度误差 |
| `e_V` | `V - V_c` | 速度误差 |

**约定**：误差定义为"实际 - 指令"，所以**误差为正表示超标了**。

## 7.3 第二步：外环——从高度误差到航迹角指令

### 已知的运动学关系

```
dh/dt = V·sin(γ)
```

### 想要什么

我们希望高度误差按一阶规律衰减：

```
dh/dt = dh_c/dt - k_h · e_h
```

其中 `k_h > 0` 是增益。这个式子的含义：如果高度高了（e_h > 0），就让高度**下降**（dh/dt 比指令值小）。

**代入并解出 γ**：

```
V·sin(γ_d) = dh_c/dt - k_h·e_h

γ_d = arcsin[ (dh_c/dt - k_h·e_h) / V ]
```

### 加上高度率阻尼

**为什么要加**：本工程的对象是**高度不稳定**的（第 5 章），而且浮沉模态发散。单纯的比例控制在相位不足时会振荡。

加一个"高度率反馈"相当于给系统加阻尼。高度率可以从状态直接算：

```
dh/dt = V·sin(γ)      （不用数值微分，直接合成）
```

最终的外环律：

```
γ_d = arcsin[ sat( (dh_c/dt - k_h·e_h - k_hd·(dh/dt - dh_c/dt)) / V , sin(γ_max) ) ]
```

- `sat(·, sin(γ_max))`：限幅，防止指令过大（本工程 γ_max = 12°）
- `k_hd`：高度率阻尼增益

**为什么限幅**：如果高度误差很大（比如指令从 0.35 m 突降到 0.10 m），`arcsin` 的参数可能超过 1，数学上无解。而且实际飞行也不允许过大的航迹角。

### 指令滤波

`γ_d` 可能因为指令突变而不光滑。让它通过一阶低通滤波器：

```
τ_g · dγ_c/dt = γ_d - γ_c
```

- `γ_c`：滤波后的航迹角指令（实际使用的）
- `τ_g`：时间常数

**注意**：`τ_g` 是**必须仔细选**的参数。本工程调试时一开始取了 0.20 s，结果高度环相位裕度不足。（见第 9 章）

## 7.4 第三步：中环——从航迹角到俯仰角（一个漂亮的恒等式）

### 关键恒等式

```
γ = θ - α
```

### 做法

直接令俯仰角指令为：

```
θ_d = γ_c + α
```

### 为什么这是对的（很重要，很多人以为是"凑"的）

假设俯仰角回路能完美跟踪，即 `θ = θ_d`。代入：

```
θ = γ_c + α
=> γ = θ - α = (γ_c + α) - α = γ_c
```

**γ 就自动等于指令值 γ_c。**

关键在于：**这个推导只用到了运动学恒等式 γ = θ - α，与控制律无关，与模型无关。**

### 这个结构的一个额外好处

如果升力模型不准确，会怎样？

假设真实升力比模型小，飞机会下沉，迎角会**自动**变化。但因为 `θ_d` 里含**实测的 α**，所以 θ 会跟着 α 一起变，`γ = θ - α` 仍然等于 γ_c。

**也就是说：升力误差被迎角反馈自动补偿掉了。**

**这就是为什么本工程不需要单独的"升力通道神经网络"**——一个漂亮的结论，省掉了一整套网络。

### 加上限幅

```
θ_d = sat(γ_c + α, θ_max)
```

`θ_max = 20°` 是**飞行包线保护**：防止控制器为追高度把飞机拉到失速迎角。

**为什么需要这个保护**：本工程调试时，曾经因为控制器失误把飞机拉到 11.6° 迎角，接近失速。有了限幅，即使控制器出错，飞机也不会进入危险姿态。

## 7.5 第四步：内环——DSC 动态面

### 目标

让俯仰角 θ 跟踪 θ_d。

### 传统反步法的做法

定义误差 `e_θ = θ - θ_d`，令期望角速度：

```
q_d = dθ_d/dt - k_θ·e_θ
```

**问题**：需要 `dθ_d/dt`（指令的导数）。而 `θ_d = γ_c + α`，求导要算 `dγ_c/dt + dα/dt`，其中 `dα/dt` 又是状态方程的一部分……**表达式会越来越长，这就是"微分爆炸"。**

### DSC 的做法

**不去解析求导，而是让 θ_d 通过一个一阶低通滤波器**：

```
τ_θ · dθ_c/dt = θ_d - θ_c
```

- `θ_c`：滤波后的俯仰角指令
- **`dθ_c/dt` 可以直接从滤波器方程读出来**：`dθ_c/dt = (θ_d - θ_c)/τ_θ`

这就**避免了求导**。

### 得到角速度指令

```
q_d = (θ_d - θ_c)/τ_θ - k_θ·(θ - θ_c)
```

（第一项就是 `dθ_c/dt`）

### 再用一次 DSC

角速度指令 `q_d` 同样需要滤波（原因相同）：

```
τ_q · dq_cf/dt = sat(q_d) - q_cf
```

- `q_cf`：滤波后的角速度指令（cf = command filtered）
- `sat(q_d)`：角速度指令限幅（本工程 6 rad/s）

### 最终得到期望角加速度

```
e_q = q - q_cf

ν = dq_cf/dt - k_q·e_q
        = (sat(q_d) - q_cf)/τ_q - k_q·e_q
```

**ν 就是"我想要的角加速度"**。它由两部分组成：

- 前馈项：指令本身的角加速度
- 反馈项：`-k_q·e_q` 把角速度误差拉回来

## 7.6 第五步：动态逆控制律

### 力矩方程

```
I_yy · dq/dt = M
```

把力矩分解成"零舵偏部分"和"舵偏贡献部分"：

```
M = M0(x) + M_δe · δ_e
```

- `M0(x)`：舵偏为零时，由迎角、速度、高度等决定的气动力矩
- `M_δe`：操纵导数，即"每偏 1 弧度舵，力矩变化多少"。本工程约 **-45 N·m/rad**
- 注意**负号**：正舵偏（后缘下偏）产生**低头**力矩（这是航空标准约定）

### 反解

令 `f0 = M0/I_yy`（零舵偏角加速度）、`b = M_δe/I_yy`（操纵效能），则：

```
dq/dt = f0 + b·δ_e
```

要让 `dq/dt = ν`，解出：

```
δ_e = (ν - f0) / b
```

**这就是动态逆**。

### 加上补偿项

因为 `f0` 和 `b` 都是**名义模型**的值，与真实有差异，所以加上补偿：

```
δ_e,指令 = (ν - f0 - u_M - u_r) / b
```

- `u_M`：RBF 神经网络的补偿（下节讲）
- `u_r`：鲁棒项（再下节讲）

### 补偿后发生了什么（关键推导）

真实系统的角加速度是：

```
dq/dt = f_真实 + b_真实·δ_e
```

设真实与名义的差为 `Δf = f_真实 - f0`（假设 `b` 的误差可以忽略），代入控制律：

```
dq/dt = (f0 + Δf) + b · [ (ν - f0 - u_M - u_r)/b ]
      = f0 + Δf + ν - f0 - u_M - u_r
      = ν + Δf - u_M - u_r
```

**看这个结果**：

- 如果 `u_M = Δf` 且 `u_r = 0`，那么 `dq/dt = ν` —— **完全精确！**
- 如果 `u_M` 有残差 `ε`，那么 `dq/dt = ν + ε - u_r` —— **鲁棒项负责吃掉 ε**

**这就是整个设计的思想**：动态逆负责"用已知的模型反解"，神经网络负责"学出未知的差异"，鲁棒项负责"兜住学不到的部分"。**三者分工明确。**

### 误差动态

由 `ν = dq_cf/dt - k_q·e_q` 和 `e_q = q - q_cf`：

```
de_q/dt = dq/dt - dq_cf/dt
        = (ν + Δf - u_M - u_r) - dq_cf/dt
        = (dq_cf/dt - k_q·e_q + Δf - u_M - u_r) - dq_cf/dt
        = -k_q·e_q + (Δf - u_M) - u_r
```

这个式子后面 Lyapunov 证明要用。

## 7.7 第六步：RBF 神经网络

### 网络结构

用 `N` 个"基函数"的加权和：

```
u_M = Σ(j=1..N) W1j · φj(z)
```

写成人向量形式：

```
u_M = W1^T · φ(z)
```

- `z`：输入向量
- `φj(z)`：第 j 个基函数（高斯钟形）
- `W1`：权值向量

### 基函数

```
φj(z) = exp( -0.5 · Σ(i=1..3) [ (zi - cji)² / σi² ] )
```

- `cj`：第 j 个节点的**中心**
- `σi`：第 i 维的**宽度**

### 输入选什么

**这是需要物理判断的地方。** 力矩失配 `ΔM` 依赖什么？看第 3 章的模型：

| 失配来源 | 依赖 |
|---|---|
| 地效强度失配 | 高度 h、迎角 α |
| RAM 效应 | 高度 h、迎角 α |
| 失速软化 | 迎角 α |
| 俯仰阻尼失配 | 角速度 q |

所以取三维输入：

```
z = [α, q, h]
```

**为什么不是四维（加上 V）**：速度的影响已经被动压 q∞ 包含了，而我们在回归向量里乘了 q∞（见下），所以不需要额外输入。**这是"用物理知识减少神经网络规模"的典型做法**——每增加一个输入维，节点数就要乘以 5。

### 归一化

三个输入的物理量级差别巨大（α 约 0.07 rad、q 约 0.5 rad/s、h 约 0.2 m）。**必须先归一化**，否则距离度量会被大数主导：

```
z_norm = 2·(x - x_min)/(x_max - x_min) - 1
```

映射到 [-1, 1] 区间。

### 中心和宽度怎么选

**在归一化坐标的 [-1,1]³ 立方体上均匀布网格。**

- 输入 1（α）：5 个中心
- 输入 2（q）：3 个中心
- 输入 3（h）：5 个中心
- 总计 5×3×5 = **75 个节点**

**宽度取网格间距**。以 5 个中心为例，间距 = 2/(5-1) = 0.5，所以 σ = 0.5。

**为什么这样选**：相邻基函数在中心处的重叠度是 `exp(-0.5) ≈ 0.61`，这个重叠度保证了：

- 不会太稀疏（中间出现"空洞"，网络无法逼近）
- 不会太密集（浪费节点，且导致回归向量范数过大——这在第 9 章是个大坑）

### 回归向量的量纲处理（关键细节）

神经网络的输出 `u_M` 的物理单位应该是**角加速度 rad/s²**（因为它要和 `ν` 相加减）。

而 `W1^Tφ` 里，`φ` 是无量纲的（0~1），所以 `W1` 的单位是 rad/s²。

但**理想权值**应该代表什么？如果让 `W1` 直接表示力矩差 `ΔM`（单位 N·m），那 `u_M` 就要除以 `I_yy`：

```
u_M = W1^T·φ / I_yy
```

写成"回归向量"形式（把缩放放进 φ）：

```
φ1 = φ(z) · (q∞·S·c / I_yy)
u_M = W1^T · φ1
```

**为什么要乘 `q∞·S·c`（动压×面积×弦长）而不是直接除以 I_yy**：

因为气动力矩的大小本身**正比于动压**。我们希望网络学的是**无量纲的力矩系数差 `ΔC_m`**，而不是有量纲的力矩。这样：

- 速度变化时，网络不需要重新学
- 权值的物理意义明确（就是力矩系数）
- 权值量级稳定（大概 0.1 ~ 1）

**完整写法**：

```
ΔM ≈ q∞·S·c · [W1*^T·φ(z)]
u_M = (q∞·S·c / I_yy) · W1^T·φ(z) = W1^T·φ1
```

**这个量纲处理是正确的，但它带来一个副作用**：回归向量被放大了 `q∞Sc/I_yy ≈ 66` 倍，而自适应回路里的"有效推进量"与回归向量范数的**平方**成正比（放大约 `66² ≈ 4391` 倍）。这个平方关系在后面会引起一个严重问题——**自适应增益必须相应缩小同一个倍数，否则会失稳**。（第 9 章详述，定量的判据在第 7.12 节）

## 7.8 第七步：自适应律

### 从哪来

**自适应律不是猜的，是从 Lyapunov 函数倒推出来的。**

思路：先写出误差动态（7.6 节已经得到）：

```
de_q/dt = -k_q·e_q + (Δf - u_M) - u_r
```

设理想权值 `W1*` 使得 `Δf ≈ W1*^Tφ1`，权值误差 `ΔW1 = W1 - W1*`，则：

```
Δf - u_M = W1*^Tφ1 - W1^Tφ1 = -ΔW1^Tφ1
```

所以：

```
de_q/dt = -k_q·e_q - ΔW1^Tφ1 - u_r + ε1
```

（`ε1` 是网络的逼近残差）

现在构造 Lyapunov 函数：

```
V1 = 0.5·e_q² + 0.5·ΔW1^T·Γ1^-¹·ΔW1
```

求导：

```
dV1/dt = e_q·de_q/dt + ΔW1^T·Γ1^-¹·dΔW1/dt
```

（注意 `dΔW1/dt = dW1/dt`，因为 `W1*` 是常数）

代入 `de_q/dt`：

```
dV1/dt = e_q·(-k_q·e_q - ΔW1^Tφ1 - u_r + ε1) + ΔW1^T·Γ1^-¹·dW1/dt
       = -k_q·e_q² - e_q·ΔW1^Tφ1 - e_q·u_r + e_q·ε1 + ΔW1^T·Γ1^-¹·dW1/dt
```

**关键一步**：我们希望中间两项抵消。也就是让：

```
ΔW1^T·Γ1^-¹·dW1/dt = e_q·ΔW1^T·φ1
```

因为这对任意 `ΔW1` 都要成立，所以：

```
Γ1^-¹·dW1/dt = e_q·φ1
```

两边乘 `Γ1`：

```
dW1/dt = Γ1 · φ1 · e_q
```

**这就是自适应律。** 它的形式完全是为了让 Lyapunov 导数里的交叉项对消。

### 力矩通道的完整自适应律

加上一个"泄漏项"防止权值漂移（叫 **e-修正**）：

```
dW1/dt = Γ1 · ( φ1·e_q - ν_e·|e_q|·W1 )
```

- `Γ1`：自适应增益（学习率）
- `ν_e`：泄漏系数

### 速度通道的自适应律（符号相反！）

速度通道的推导类似，但**符号是反的**。原因在于估计量在控制律里的位置不同：

**力矩通道**：`δ_e = (ν - f0 - u_M - ...)/b`
-> `dq/dt = ν + Δf - u_M - ...` -> **u_M 以减号进入**

**速度通道**：`T = m·(dV_d + u_D - u_rV) + D0 + ...`
-> `dV/dt = dV_d + u_D - ΔD/m - ...` -> **u_D 以加号进入**

因为进入了不同的符号位置，为了让 Lyapunov 交叉项对消，自适应律的符号也必须相反：

```
力矩通道： dW1/dt = + Γ1·(φ1·e_q - ...)
速度通道： dW2/dt = - Γ2·(φ2·e_V + ...)
```

**这是一个极其隐蔽的坑。** 本工程调试时就写反了速度通道的符号，导致推力-速度回路出现发散的实极点。**推导时一定要把每一步的符号写清楚。**（第 9 章）

### 投影算子：保证权值有界

**为什么需要**：Lyapunov 证明要求 `ΔW` 有界。如果没有界，`ΔW1^TΓ^-¹ΔW1` 可能无限增大，证明就不成立。

**投影算子的定义**：

```
如果 ‖W‖ < W_max，或者 (‖W‖ = W_max 且 W^T·τ ≤ 0)：
    输出 = τ
否则：
    输出 = τ - (W·W^T/‖W‖²)·τ
```

**几何理解**：

- 第一种情况：权值在球内，或者虽然在球面上但正要往球内走 -> 正常更新
- 第二种情况：权值在球面上且想往外走 -> **把更新的径向分量去掉**，只保留切向分量

**效果**：权值永远待在半径 `W_max` 的球内。

**为什么用它而不是直接裁剪**：直接裁剪（`W = min(W, W_max)`）是不连续的，会破坏 Lyapunov 的负定性。投影算子是**光滑**的，只做"去掉径向分量"这一个动作，不破坏证明。

## 7.9 第八步：鲁棒项

```
u_r = η_r · tanh( e_q / Φ_r )
```

- `η_r`：鲁棒增益，必须满足 `η_r ≥ ε_N + d_max`（网络残差上界 + 扰动上界）
- `Φ_r`：边界层厚度

**"边界层"的含义**：误差在 ±Φ_r 以内时，tanh 近似线性；超出后饱和。

**取值原则**：`η_r/Φ_r`（零点等效增益）**不能太大**。本工程最终取 `η_r = 2.5`、`Φ_r = 0.8`，等效增益约 3.1。而最初取 `Φ_r = 0.06` 时等效增益 20，直接把相位裕度吃光。

**经验法则**：鲁棒项的零点等效增益应当**不超过该回路比例增益的量级**。

## 7.10 第九步：速度回路

速度方程（切向）：

```
dV/dt = [T·cos(α+i_T) - D - m·g·sin(γ)] / m
```

反解推力：

```
T_指令 = [ m·(dV_d + u_D - u_rV) + D0 + m·g·sin(γ_c) ] / cos(α + i_T)
```

其中：

```
dV_d = dV_c/dt - k_V·e_V - k_IV·I_V        （期望加速度）
I_V = ∫e_V dt                               （误差积分，消除稳态误差）
```

**注意两个细节**：

**细节 1：重力前馈取自 `γ_c` 而不是 `γ`。**
如果取实测的 γ，会形成一条正反馈回路：

```
γ 增大 -> 指令推力增大 -> 推力增大 -> 速度增大 -> 升力增大 -> dγ/dt 增大 -> γ 再增大
```

这条回路增益是 `m·g = 117.7 N/rad`，非常大。改成用指令值 `γ_c` 就**切断了这条回路**。（第 9 章）

**细节 2：鲁棒项前面是减号。**
和力矩通道一样，为了让误差动态里出现 `-u_rV`，控制律里必须写成 `- u_rV`。写反了就是正反馈。

## 7.11 第十步：Lyapunov 稳定性证明

现在把上面的东西串起来，证明闭环系统是**一致最终有界（UUB）**的。

### 构造 Lyapunov 函数

```
V_L = 0.5·e_q² + 0.5·ΔW1^TΓ1^-¹ΔW1 + 0.5·e_V² + 0.5·ΔW2^TΓ2^-¹ΔW2 + 0.5·k_IV·I_V²
```

**物理类比**：这是一个"广义能量"。第一项是角速度误差的"动能"，第二项是权值误差的"势能"，依此类推。

**证明的目标**：证明这个"能量"随时间**单调下降**（至少是最终下降）。

### 求导并代入

把误差动态和自适应律代进去。**力矩通道的交叉项**：

```
e_q·(-ΔW1^Tφ1) + ΔW1^TΓ1^-¹·(Γ1·φ1·e_q)
= -e_q·ΔW1^Tφ1 + ΔW1^T·φ1·e_q
= 0     √ 精确对消
```

**速度通道的交叉项**（注意符号）：

```
e_V·(ΔW2^Tφ2) + ΔW2^TΓ2^-¹·(-Γ2·φ2·e_V)
= e_V·ΔW2^Tφ2 - ΔW2^T·φ2·e_V
= 0     √ 也对消了
```

**这就是为什么两个通道的自适应律符号必须相反。**

### 剩下的项

对消之后剩下：

```
dV_L/dt = -k_q·e_q² - k_V·e_V² - k_IV·k_IV^-¹·(...) 
          + e_q·(ε1 + d_M) - e_q·u_r
          + e_V·(ε2 + d_V) - e_V·u_rV
```

（`d_M`、`d_V` 是外部扰动）

### 用不等式放缩

对鲁棒项，用这个经典不等式：

```
|z| - z·tanh(z/Φ) ≤ 0.2785·Φ
```

它的含义：`tanh` 和 `sign` 的差别被一个常数界住。

因为 `η_r ≥ ε_N + d_M`（鲁棒增益足够大），可以推出：

```
e_q·(ε1 + d_M) - e_q·η_r·tanh(e_q/Φ_r) ≤ η_r·0.2785·Φ_r
```

对速度通道同理。

### 得到最终的微分不等式

```
dV_L/dt ≤ -2·λ_min·V_L + c0
```

其中 `c0 = 0.2785·(η_r·Φ_r + η_V·Φ_V)`，`λ_min` 是所有回路增益里最小的那个。

### 解这个不等式

这是一个标准的线性微分不等式，解出来：

```
V_L(t) ≤ V_L(0)·exp(-2λ_min·t) + c0/(2λ_min)
```

**结论（UUB）**：

```
‖误差(t)‖ ≤ sqrt( 2·V_L(0)·exp(-2λ_min·t)/λ_min + c0/λ_min )
```

### 怎么读这个结论

**两项的含义**：

- **第一项**：和初始误差有关，随时间**指数衰减**（收敛速度由 λ_min 决定）
- **第二项**：`sqrt(c0/λ_min)`，是一个**常数**，代表最终误差的界

**关键理解**：

1. **误差不能收敛到零**，只能收敛到一个半径 `sqrt(c0/λ_min)` 的球内。原因是 `c0 ≠ 0`（因为网络残差 `ε ≠ 0`）。
2. **想减小最终误差**，有两条路：
   - 增大 `λ_min`（提高控制增益）——但受相位裕度限制
   - 减小 `c0`（增大鲁棒增益 η 或减小边界层 Φ）——但受"等效增益不能太大"限制
3. **这就是控制理论里的"没有免费午餐"**：性能和鲁棒性永远在权衡。

### 级联系统的处理

上面只证明了内环（俯仰、速度通道）。外环（高度）是级联结构：

```
de_h/dt = dh/dt - dh_c/dt
        = V·sin(γ) - dh_c/dt
```

而 `γ_d` 是按"要让高度误差一阶衰减"设计的，所以：

```
de_h/dt = -k_h·e_h + V·(sin(γ) - sin(γ_c))
```

**第一项是好项（负定），第二项是内环跟踪误差的贡献。**

因为我们已经证明了内环误差是有界的（UUB），所以第二项有界，于是：

```
de_h/dt ≤ -k_h·e_h + (有界量)
```

用同样的方法（解线性不等式），可以证明 `e_h` 也是**一致最终有界**的。

**总结**：内环 UUB + 外环输入有界 -> 整个闭环 UUB。这就是**级联系统的稳定性传递**。

## 7.12 第十一步：离散化——一个必须面对的问题

### 问题

上面的自适应律都是连续时间的微分方程。但**真实飞控是数字计算机，按固定周期采样**。

本工程用前向欧拉法离散：

```
W(k+1) = W(k) + T_s · Γ · φ · e(k)
```

其中 `T_s = 0.005 s`（200 Hz）。

### 离散化的稳定性条件

**这个推导很关键，我们一步步来。** 注意：这里最容易犯的错是"只盯着回归向量范数"，而得出的判据里还必须带上该通道的**比例增益**。

#### 第一步：只取两个状态

自适应回路里同时活跃的量很多（q、α、h、V、权值……），但判断"采样会不会把自适应回路搞散"时，只需要看**两个状态**：

```
e(k)   —— 该通道的跟踪误差（力矩通道是 e_q，速度通道是 e_V）
W(k)   —— 该通道的权值
```

其余动态（对象、执行器、其他回路）在自适应收敛的时间尺度上变化慢得多，**当作冻结**。泄漏项（e-修正）和投影算子也先忽略——它们只会让系统更保守，不会让判据失效。

#### 第二步：写出两状态线性化模型

以力矩通道为例。误差动态与自适应律（7.8 节）取离散前向欧拉：

```
e(k+1) = e(k)·(1 - T_s·k_q) - T_s·φ1^T·ΔW(k)
W(k+1) = W(k) + T_s·Γ1·φ1·e(k)
```

用状态向量 `[e; ΔW]` 写成矩阵形式：

```
[ e(k+1) ]   [ 1 - T_s·k_q      -T_s·φ1^T ] [ e(k) ]
|        | = |                            | |      |
[ ΔW(k+1)]   [ T_s·Γ1·φ1         I       ] [ ΔW(k)]
```

**特征多项式**（按权值误差方向投影后，N 维权值退化成标量 ‖φ1‖²）：

```
λ² - (1 - T_s·k_q)·λ + (1 - T_s·k_q + T_s²·Γ1·‖φ1‖²) = 0
```

#### 第三步：用 |det| < 1 得到判据

这个二阶系统的两个特征根之积（= 常数项）就是系数矩阵的行列式：

```
det = 1 - T_s·k_q + T_s²·Γ1·‖φ1‖²
```

**稳定要求 `|det| < 1`**。拆成两个不等式：

- `det < 1` → `T_s²·Γ1·‖φ1‖² < T_s·k_q` → 两边约去 `T_s` →

```
T_s · Γ1 · ‖φ1‖²  <  k_q
```

- `det > -1` → `T_s²·Γ1·‖φ1‖² > T_s·k_q - 2`，当 `T_s·k_q < 2` 时这个下界是负的，自动满足。

**所以真正的判据是**：

```
T_s · Γ_i · ‖φ_i‖²  <  k_i          （i = 1 力矩通道，i = 2 速度通道）
```

其中：

- **`k_i` 是该通道的误差反馈比例增益**（力矩通道 `k_q = 6.00`，速度通道 `k_V = 1.53`）
- **`φ_i` 是完整的回归向量，包含量纲缩放因子**：

```
φ1 = φ_rbf · ( q∞·S·c / I_yy )        ← 7.7 节那个 66 倍的缩放
φ2 = φ_rbf / m
```

- 另一条常被忽略的约束来自 `det > -1`：`T_s·k_i < 2`，即**误差反馈本身的欧拉离散约束**。

**为什么它和"|1 - T_s·Γ·g²| < 1"那种写法不同**：那种写法只看自适应项，漏掉了 `k_i` 这个"恢复力"。物理上很清楚——误差被比例增益 `k_i` 往回拉、被自适应项 `T_s·Γ_i·‖φ_i‖²` 往外推，**判据是两者比大小**，不是自适应项自己小于某个常数。

### 代入本工程的数字

**配平点**：V = 18 m/s、h = 0.20 m。

**第一步：量纲缩放因子**

```
q∞ = 0.5 × 1.225 × 18²  = 198.45 Pa
g1 = q∞·S·c / I_yy = 198.45 × 0.96 × 0.40 / 1.15 = 66.265 s^-2
g2 = 1 / m         = 1 / 12.0                    = 0.083333 kg^-1
```

**第二步：高斯基函数的范数**（75 个节点、σ = 0.5 的网格，在配平点附近的归一化坐标上取值）

```
‖φ1,rbf‖² = 5.3943
‖φ2,rbf‖² = 5.3744
```

（两者数值接近不是巧合——两个通道的网络结构相同，只是输入向量第三维不同：力矩通道用 q，速度通道用 V。）

**第三步：把缩放因子乘进去**

```
‖φ1‖² = g1² · ‖φ1,rbf‖² = 66.265² × 5.3943 = 4391.0 × 5.3943 ≈ 2.369e4  [1/s^4]
‖φ2‖² = g2² · ‖φ2,rbf‖² = 0.083333² × 5.3744 = 6.944e-3 × 5.3744 ≈ 3.732e-2  [1/kg^2]
```

**第四步：代入判据**

| 通道 | `T_s·Γ_i·‖φ_i‖²` | 比例增益 `k_i` | 裕度比 `k_i / (T_s·Γ_i·‖φ_i‖²)` | 结论 |
|---|---|---|---|---|
| 力矩（Γ1 = 0.005） | **0.5922** | k_q = 6.00 | **10.1** | 满足，裕度 10 倍 |
| 速度（Γ2 = 3.0） | **5.598e-4** | k_V = 1.53 | **2733** | 满足，裕度极大 |

两个通道都满足 `T_s·Γ_i·‖φ_i‖² << k_i`，**离散自适应回路稳定**。力矩通道的裕度只有 10 倍，是两者中**更紧张**的那个——这也说明为什么调试时真正要盯的是 Γ1，而不是看起来"大得多"的 Γ2。

**如果回到最初那版 Γ1 = 45**：

```
T_s·Γ1·‖φ1‖² = 0.005 × 45 × 2.369e4 ≈ 5328     >>  k_q = 6
```

**超出判据近 900 倍**，自适应回路必然在几个采样周期内发散——这与当时观察到的"权值在 10 个采样周期内冲到投影上界、舵面瞬间饱和"完全一致。

**历史版本的错误**：本教程早期把判据写成 `T_s·Γ·g² < 0.1`（工程）／`< 2`（绝对），据此推出 `Γ < 0.0023`，然后又承认实际用的 `Γ1 = 0.005` 超了——这是一个自相矛盾的结论。错误的根源有两个：一是把判据里的 `k_i` 漏掉了；二是把 `‖φ_rbf‖²` 当成 1~3 的常数去估，而实际值在配平点是 5.39。**修正后的判据不再是"某个魔数 0.1"，而是与该通道比例增益的比值**，物理意义清楚，也不会再自相矛盾。

### 为什么两个通道的增益数字差这么多

| 通道 | 增益 | 量纲缩放因子 g | 说明 |
|---|---|---|---|
| 力矩 | Γ1 = **0.005** | q∞Sc/I_yy ≈ **66.265 s^-2** | 回归向量被放大 4391 倍（平方后 2.369e4） |
| 速度 | Γ2 = **3.0** | 1/m ≈ **0.083333 kg^-1** | 回归向量被缩小到 1/144 |

**两个缩放因子本身差了 `66.265 / 0.083333 ≈ 795` 倍**，平方之后是 `6.34e5` 倍。回归向量放大得越厉害，同样的 Γ 产生的权值更新就越大，所以力矩通道的 Γ 必须相应地小得多——**这才是两组增益数字相差 600 倍的真正原因**。

注意 **但这里有一个必须纠正的说法**：不能因为"缩放的差异被增益的差异抵消了"就宣称两个通道的**有效学习率 `Γ·g²` 是同一量级**。恰恰相反：

```
力矩：Γ1·g1² = 0.005 × 4391 = 21.8
速度：Γ2·g2² = 3.0 × 6.944e-3 = 0.0207
```

**两者相差约 1000 倍（三个数量级）**，根本不是同一量级。之所以能用，是因为判据里的比较基准 `k_i` 也不同（6.00 vs 1.53），而且两个通道的**误差量纲不同**（e_q 是 rad/s，e_V 是 m/s），初始误差量级也不同，`Γ·g²` 这个量本身**不具备跨通道可比性**。

**有意义的比较量是无量纲的比值**：

```
T_s·Γ_i·‖φ_i‖² / k_i ：  力矩 0.0987     速度 3.66e-4
```

这两个数才是"离失稳边界还有多远"的正确度量，**两者都远小于 1**，说明两个通道都安全；力矩通道是相对更紧张的那个。

**教训：自适应增益不能凭感觉给，也不能只看 `Γ` 的数值大小。要按该通道的无量纲数 `T_s·Γ_i·‖φ_i‖² / k_i` 来判断，它必须远小于 1。**

## 7.13 本章小结

- 控制问题拆成两条链：**高度链（四级级联）** 和 **速度链**。
- 外环用**比例 + 高度率阻尼**，高度率由 `V·sin(γ)` 直接合成。
- **`θ_c = γ_c + α` 是由恒等式 `γ = θ - α` 保证的**，与控制律无关；它还自动补偿了升力误差。
- **DSC 用一阶滤波器代替解析求导**，解决微分爆炸。
- **动态逆 = 用模型反解控制量**；补偿后误差动态变成 `de/dt = -k·e - ΔW^Tφ - u_r + ε`。
- **自适应律是从 Lyapunov 函数倒推的**，形式完全为了让交叉项对消。
- **两个通道的自适应律符号相反**，因为估计量在控制律里位置不同。
- **投影算子保证权值有界**，且不破坏 Lyapunov 负定性。
- **鲁棒项用 tanh**，零点等效增益 `η/Φ` 不能太大。
- **UUB 结论**：误差指数收敛到半径 `sqrt(c0/λ_min)` 的球内，不能到零。
- **离散稳定性条件 `T_s·Γ_i·‖φ_i‖² < k_i`**（`φ_i` 含量纲缩放、`k_i` 是该通道比例增益）：忘记这一条会导致权值几个周期内爆掉。要比较的是无量纲比值 `T_s·Γ_i·‖φ_i‖² / k_i`，不是 `Γ` 的数值大小。
