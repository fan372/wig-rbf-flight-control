## 11.3 数学工具速查

### 泰勒展开与线性化

```
f(x) ≈ f(x0) + f'(x0)·(x - x0)
```

多元形式：偏导数排成雅可比矩阵。

### 中心差分

```
f'(x) ≈ [f(x+Δ) - f(x-Δ)] / (2Δ)
```

**步长选择**：Δ = 10^-6 × max(1, |x|)。太小有舍入误差，太大有非线性误差。

### 复特征值

```
λ = σ ± jω
ω_n = |λ| = √(σ² + ω²)        固有频率
ζ = -σ/ω_n                     阻尼比
时间常数 = 1/|σ|
```

- σ < 0：稳定；σ > 0：发散
- ζ < 1：欠阻尼（振荡）；ζ > 1：过阻尼

### 一阶惯性环节

```
τ·dy/dt = u - y
```

- 阶跃响应：`y(t) = u·(1 - e^(-t/τ))`
- 3τ 到达约 95%
- 带宽 ≈ 1/τ (rad/s)

### 欧拉法离散的稳定条件

```
y(k+1) = y(k) + T_s/τ · (u - y(k))
         = y(k)·(1 - T_s/τ) + ...
```

要求 `|1 - T_s/τ| < 1`，即 **`T_s/τ < 2`**。

### 离散自适应律的稳定条件

自适应律 + 误差反馈的两状态线性化系统，特征多项式为：

```
λ² - (1 - T_s·k_i)·λ + (1 - T_s·k_i + T_s²·Γ_i·‖φ_i‖²) = 0
```

由 `det < 1` 得到判据（`k_i` = 该通道比例增益，`φ_i` = 含缩放因子的完整回归向量）：

```
T_s · Γ_i · ‖φ_i‖²  <  k_i
```

本工程配平点（V = 18 m/s、h = 0.20 m）代入值：

| 通道 | `T_s·Γ_i·‖φ_i‖²` | `k_i` | 裕度比 |
|---|---|---|---|
| 力矩（Γ1 = 0.005） | 0.5922 | k_q = 6.00 | 10.1 |
| 速度（Γ2 = 3.0） | 5.598e-4 | k_V = 1.53 | 2733 |

### 双曲正切不等式

```
|z| - z·tanh(z/Φ) ≤ 0.2785·Φ
```

用于鲁棒项的 Lyapunov 放缩。

### 常用小角度近似（< 10°）

```
sin(x) ≈ x,  cos(x) ≈ 1 - x²/2 ≈ 1,  tan(x) ≈ x
```

## 11.4 常见问题 FAQ

**Q1：为什么不用 PID？PID 不是万能的吗？**

PID 是"万能"的，但前提是**对象特性已知且不剧烈变化**。本工程的对象有三个 PID 无法处理的特点：

1. 气动参数随高度非线性剧变（±40%）
2. 对象本身不稳定（浮沉模态 ζ < 0）
3. 存在模型里根本没有的效应（RAM 效应）

而且本工程实测过：PID 结构在高度机动时会触地。

**Q2：神经网络会不会"学坏"，把飞机搞得更糟？**

有三重保护：

1. **投影算子**限制权值范数上界
2. **局部支撑**：飞出训练范围时网络输出自动趋零，退化为"动态逆 + 鲁棒项"
3. **饱和冻结**：执行器饱和时停止学习，避免学错

**Q3：为什么不用更深的神经网络（比如 LSTM）？**

三个原因：

1. **Lyapunov 证明需要"对权值线性"**。深层网络做不到。
2. **实时性**：200 Hz 采样意味着 5 ms 内要算完，深层网络推理太慢。
3. **可解释性**：RBF 的权值有明确物理意义（力矩系数），深度网络是黑箱，出了事没法查。

**Q4：为什么高度控制不用气压高度表，而要用雷达高度计？**

气压高度表测的是**绝对高度**（相对海平面），精度约几米。而我们需要的精度是**厘米级**。只有雷达/激光测距才能达到。

**Q5：如果雷达高度计失灵怎么办？**

这是**适航性**问题。工程上通常的做法：

- 冗余传感器 + 表决
- 高度低到阈值时自动拉起（包线保护）
- 本工程的代码里已经有 `θ_max = 20°` 这样的保护，但**没有做传感器故障检测**——这是下一步工作。

**Q6：为什么仿真步长是 1 ms，而控制器是 5 ms？**

- 控制器 5 ms：模拟真实飞控计算机的采样周期（200 Hz 是航空常用的速率）
- 积分 1 ms：为了让被控对象的数值积分足够精确

**两者必须分开**。如果积分步长也用 5 ms，舵机动态（τ = 0.05 s）只有 10 个积分点，精度不够。

**Q7：为什么要在模型里故意制造失配？这不是自找麻烦吗？**

**恰恰相反。** 如果真实对象和控制器模型完全一致，那么：

- 仿真会很容易通过
- 但**什么也证明不了**——因为真实世界永远不会有"模型完全准确"的情况

**故意制造失配，是为了让仿真结果有工程意义。**

**Q8：这个控制器能直接上真机吗？**

**不能，还差几步**：

1. 需要真实的气动数据（CFD 或风洞）替换当前的**工程估算值**——注意本工程的地效参数 A、n 只是按公开趋势选定的，**没有做过 CFD，也没有做过风洞试验**，`ANSYS/` 目录目前只有接口模板，且模板数据是由本工程解析式反向生成的
2. 需要传感器故障检测与冗余管理
3. 需要半物理仿真（HIL）验证
4. 需要飞行试验逐步放开包线

**本工程完成的是"理论与仿真验证"这一步。**

**Q9：为什么自适应增益两个通道差了 600 倍？**

因为回归向量的量纲不同：力矩通道的回归向量是 `φ1 = φ_rbf·(q∞Sc/I_yy)`（带 `1/s²` 量纲，配平点缩放因子 66.265 s^-2），速度通道是 `φ2 = φ_rbf/m`（带 `1/kg` 量纲，缩放因子 0.083333 kg^-1），两个缩放因子本身相差 795 倍。

**不能直接比较 Γ 的数值**，也不能比较 `Γ·g²`（力矩 21.8、阻力 0.0207，差三个数量级）。要看的是判据里的无量纲比值：

```
T_s·Γ_i·‖φ_i‖² / k_i     力矩 0.0987，速度 3.66e-4，两者都 << 1
```

**Q10：为什么不用卡尔曼滤波估计迎角？**

可以用，但本工程假设迎角可测（小型无人机用风标或 α 传感器是常规做法）。加卡尔曼滤波会增加复杂度，但对核心结论没有影响。

**如果要做**：应该估计 α 和 q，因为这两个量对噪声最敏感。

## 11.6 延伸阅读建议

按"从易到难"排序：

### 飞行力学入门

- **《飞行力学》** 或任何一本航空院校教材：讲清楚六自由度运动方程的推导
- **Etkin《Dynamics of Flight》**：经典教材，稳定性和操纵性讲得很透

### 地效飞行器

- **Rozhdestvensky, "Wing-in-ground effect vehicles"**（Progress in Aerospace Sciences, 2006）：综述，涵盖气动、稳定性、控制
- 关键词检索：`WIG craft longitudinal stability`、`ground effect aerodynamic model`

### 非线性控制

- **Khalil《Nonlinear Systems》**：Lyapunov 稳定性理论的权威教材
- **Slotine & Li《Applied Nonlinear Control》**：工程导向，反步法和自适应讲得很好

### 自适应控制与神经网络

- **Ioannou & Sun《Robust Adaptive Control》**：投影算子、σ 修正的原始文献
- **Lewis et al., "Neural Network Control of Robot Manipulators and Nonlinear Systems"**：RBF 自适应控制的经典
- **Farrell & Polycarpou《Adaptive Approximation Based Control》**：把函数逼近和控制结合得最好的一本

### 动态面控制

- **Swaroop et al., "Dynamic surface control for a class of nonlinear systems"**（IEEE TAC, 2000）：DSC 的原始论文

### 建议的阅读顺序

```
第 1 步：飞行力学教材 -> 搞懂运动方程
第 2 步：Khalil 第 4 章 -> 搞懂 Lyapunov
第 3 步：Slotine 第 6 章 -> 搞懂反步法
第 4 步：Ioannou 第 4 章 -> 搞懂自适应律和投影
第 5 步：Lewis 第 2~3 章 -> 搞懂 RBF 神经网络控制
第 6 步：回到本工程的代码，对着第 7 章的推导看
```

**不要试图一次全懂。** 这份教程的作用是给你一张地图，告诉你每一块知识在整个体系里的位置。真正理解需要反复回来对照。
