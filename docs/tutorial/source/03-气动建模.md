# 第 3 章 气动力怎么算

这一章解决"飞机受了多大的力和力矩"。这是建模的一半，另一半（这些力怎么让飞机运动）在第 4 章。

## 3.1 升力从哪来

### 一个常见的错误说法

很多人说"机翼上方气流走得快、压力低，所以产生升力"——这个说法**不完全对**。正确的说法是：

> **机翼把气流向下偏折，气流反过来把机翼向上推。**

这是牛顿第三定律。机翼每个时刻都在把大量空气往下推，空气就给机翼一个向上的反作用力。

那机翼为什么能把气流往下偏折？因为机翼有**迎角**和**弯度**——气流撞上来，被"铲"向下方。

### 量化：升力系数

把升力写成无量纲形式：

```
L = q · S · C_L       其中 q = 0.5 · ρ · V²
```

`C_L` 在小迎角下和迎角成正比：

```
C_L = a · (α - α_L0)
```

**为什么要用"系数"这种绕弯的写法？**

因为这样一来，`C_L` 就只和**形状**（翼型、迎角）有关，而与**尺寸、速度、空气密度**无关。这意味着：

- 风洞里用 1/10 缩比模型测出来的 `C_L` 曲线，可以直接用到全尺寸飞机上
- 换一个飞行速度，不用重测气动，只要改 q 就行

这是航空工程能发展的基础。

## 3.2 升力线斜率 a 是多少

理论上，二维翼型（无限长机翼）的升力线斜率是：

```
a0 = 2π ≈ 6.28  (每弧度)
```

实际因为空气有粘性、翼型有厚度，大概是 `2π × 0.9 ≈ 5.7 ~ 5.9`。本工程取 **a0 = 5.90 /rad**。

但真实的机翼是**有限长**的，所以实际升力线斜率要比 a0 小。原因就是我们下面要讲的诱导阻力。

## 3.3 有限翼展与诱导阻力

### 翼尖涡的形成

机翼下表面压力高、上表面压力低。到了翼尖，高压空气会绕过翼尖"漏"到上表面去，形成两个旋转的涡——**翼尖涡**。

这两个涡在机翼后方拖出两条长长的尾迹，涡的旋转在机翼所在位置诱导出一个**向下的速度**，叫**下洗速度 w**。

### 有效迎角变小

机翼几何上是 α，但因为气流本身在往下走，机翼实际"看到"的气流方向是斜向下的，所以**有效迎角**变小了：

```
α_有效 = α - α_i
```

其中 `α_i = w / V` 叫**诱导迎角**。

### 升力线斜率被"打折"

现在把「有效迎角」代回升力公式：

```
C_L = a0 · (α - α_i - α_L0)
```

但 α_i 本身又和 C_L 有关。对椭圆升力分布，有：

```
α_i = C_L / (π · AR · e)
```

（`AR` 是展弦比，`e` 是效率因子）

把两个式子联立：

```
C_L = a0 · (α - C_L/(π·AR·e) - α_L0)
```

把带 C_L 的项移到左边：

```
C_L · [1 + a0/(π·AR·e)] = a0 · (α - α_L0)
```

于是得到**有限翼展的实际升力线斜率**：

```
a = a0 / [1 + a0/(π·AR·e)]
```

**验算本对象**：a0 = 5.90，AR = 6.0，e = 0.85

```
π·AR·e = 3.1416 × 6.0 × 0.85 = 16.02
a = 5.90 / (1 + 5.90/16.02) = 5.90 / 1.368 = 4.31 /rad
```

比二维值 5.90 下降了 27%。**展弦比越小，下降越多**——这解释了为什么滑翔机要做得那么细长。

## 3.4 地面效应：镜像涡模型

现在进入本章核心。**地面为什么会增强升力？**

### 镜像原理

这是流体力学里的一个经典技巧，叫**镜像法**。

对于一块无限大的固体平板（地面），要让"地面处法向速度为零"这个边界条件成立，可以在**地面下方对称位置放一个"镜像"的涡系**，其旋向与真实涡系**相反**。

打个比方：你站在镜子前，镜子里有一个"你"，动作完全对称。如果真实世界和镜像世界叠加，镜面处的效果正好抵消。

### 对下洗的影响

真实翼尖涡在机翼处诱导**下洗**（把气流往下带）。

镜像涡旋向相反，所以它在机翼处诱导的是**上洗**（把气流往上带）！

两者叠加：**下洗被削弱了**。

极端情况：

- **无限高**：镜像涡离得无限远，影响为零 -> 下洗完整保留 -> 就是自由空气
- **贴地（h = 0）**：镜像涡就在机翼正下方，上洗完全抵消下洗 -> 下洗为零

**这就是地面效应的物理机制**：地面把机翼"自己吹自己"的那部分效应挡住了。

### 定义一个系数

为了把这件事量化，我们定义**地效因子 κ**（读作 kappa）：

```
κ = 贴地时的下洗 / 自由空气的下洗
```

取值范围：

- **κ = 1**：完全无地效（自由空气）
- **κ = 0**：完全贴地（下洗被完全抵消）
- **0 < κ < 1**：真实情况

于是：

```
诱导迎角：α_i(地效) = κ · α_i(自由空气)
下洗速度：w(地效)   = κ · w(自由空气)
```

**为什么说 κ 就是"下洗保留系数"**：因为它表示"自由空气的下洗还剩多少没被地面抵消"。κ 越小，地面效应越强。

## 3.5 地效因子 κ(h) 长什么样

现在需要一个**函数形式**来描述 κ 随高度 h 怎么变。

### 已知的两端

- `h → 0` 时，`κ → 0`
- `h → ∞` 时，`κ → 1`
- h 用什么归一化？用**翼展 b**，因为地面效应本质是"地面挡住了翼尖涡"，而翼尖涡的尺度就是翼展。所以用无量纲高度 `x = h/b`。

### 选择函数形式

我们选了：

```
κ(x) = x^n / (A + x^n)
```

**为什么是这个形式**，而不是别的？逐条对比：

| 候选形式 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| `κ = 1 - A/x` | 简单 | h→0 时发散到负无穷，不物理 | × |
| `κ = exp(-A/x)` | h→0 时趋零，形状合理 | h→∞ 时趋 1 很慢；参数不好拟合；不易求导 | △ |
| `κ = 1/(1+A/x^n)` | 两端行为正确 | 与上面的形式等价，但 h→0 时的幂次行为不直观 | △ |
| **`κ = x^n/(A+x^n)`** | **两端行为正确；h→0 时 κ ∝ x^n；单调；只有一个形状参数 A 和一个指数 n，拟合稳定** | h→0 时导数为 0（x^n 的 n>1 时），与部分实验数据在极低空的趋势略有差异 | **√ 选它** |

**这个形式的另一个好处**：它可以直接做**线性化拟合**。

把式子变形：

```
1/κ = (A + x^n)/x^n = 1 + A/x^n
1/κ - 1 = A/x^n
ln(1/κ - 1) = ln(A) - n·ln(x)
```

令 `y = ln(1/κ - 1)`、`u = ln(x)`，就变成一条**直线**：

```
y = ln(A) - n·u
```

**也就是说：只要有一组实测的 (h, κ) 数据，取两次对数就能用最小二乘拟合出 A 和 n。** 不需要任何非线性优化。这是选择这个函数形式的一个很实际的理由。

（代码对应：`wig_ge_fit_cfd.m`。本工程用它做了一次**往返自检**：`ANSYS/data/ge_kappa_template.csv` 是**由本工程自己的解析式生成**的模板，拟合以 `R² = 0.99874` 反演出 A = 0.06423、n = 1.45030，与生成时用的 0.0641 / 1.4622 一致。这证明了**标定算法本身写对了**，但**不构成任何模型验证**——把模型喂给算法再把参数拿回来，只是自洽性检查，不是与真实物理的比对。真正开展 CFD 之后，应当用 CFD 算出的 κ(h) 替换模板数据，那时才谈得上"标定"和"验证"。）

### 本工程的参数

取 A、n 的原则是：**让 κ(h) 跟随公开文献里地效因子随高度衰减的公认趋势**，而不是去拟合任何实测数据。也就是说——

> **本工程没有做过 CFD，也没有做过风洞试验。** A = 0.0641、n = 1.4622 是**根据公开趋势选定**的一组自洽参数，取值使 κ 在 h/b ≈ 0.02 时降到 5% 量级、在 h/b → 1 时趋于 1，与文献报道的形态一致。这是"工程估算"，不是"标定结果"。

```
A = 0.0641,  n = 1.4622
```

算出来：

| h (m) | h/b | κ | 物理含义 |
|---|---|---|---|
| 0.05 | 0.021 | **0.052** | 下洗只剩 5%，地效极强 |
| 0.10 | 0.042 | 0.130 | |
| 0.20 | 0.083 | 0.292 | 巡航点 |
| 0.35 | 0.146 | 0.483 | |
| 0.50 | 0.208 | 0.612 | 下洗还剩 61% |
| 1.00 | 0.417 | 0.813 | 地效已弱 |
| ∞ | ∞ | 1.000 | 自由空气 |

## 3.6 升力线斜率的地效修正（完整推导）

有了 κ，就能推出地效下的升力线斜率。**这一步是本章最重要的推导**，我们慢慢来。

### 第 1 步：写出自由空气的关系

前面已经推过：

```
C_L = a0 · (α - α_i - α_L0)
α_i = C_L / (π·AR·e)
```

### 第 2 步：把诱导迎角乘上 κ

地效把诱导迎角削弱了：

```
α_i(地效) = κ · C_L / (π·AR·e)
```

### 第 3 步：代入

```
C_L = a0 · [α - κ·C_L/(π·AR·e) - α_L0]
```

### 第 4 步：整理

```
C_L + a0·κ·C_L/(π·AR·e) = a0·(α - α_L0)

C_L · [1 + a0·κ/(π·AR·e)] = a0·(α - α_L0)
```

### 第 5 步：得到结果

```
a_w(h) = a0 / [1 + a0·κ(h)/(π·AR·e)]
```

**这就是地效修正后的升力线斜率。**

### 验算与物理检查

| h (m) | κ | a_w (1/rad) | 相对自由空气 |
|---|---|---|---|
| 0.05 | 0.052 | 5.79 | **+34.3%** |
| 0.20 | 0.292 | 5.33 | +23.5% |
| 0.50 | 0.612 | 4.82 | +11.7% |
| ∞ | 1.000 | 4.31 | 基准 |

**物理检查**（这一步很重要，推完公式一定要回头看看合不合理）：

- κ = 1 时，公式退化成普通有限翼展公式 √
- κ = 0 时，`a_w = a0`，即升力线斜率趋近二维值——因为下洗为零，等效于无限翼展 √
- 地效越强（κ 越小），a_w 越大 √（贴地增升）

**为什么最大只能到 a0 = 5.90**：因为地面效应只能"消除下洗"，不能"制造额外的环量"。消除下洗的极限就是等效无限翼展，也就是 a0。这是这个模型的内在上限。

> **引申：这个模型低估了什么？**
> 真实的极低空飞行（h/c < 0.2）时，机翼下方的"气垫"效应会产生**额外的**压力升高，升力可以超过 a0 给出的上限。这在工程上叫 **RAM 效应**。
> 本工程的处理方式很聪明：**把它作为"真实对象有、但控制器模型里没有"的一项**，专门用来考验自适应控制器。（见 3.9 节）

## 3.7 诱导阻力的地效修正

诱导阻力和下洗成正比，所以直接乘 κ：

```
C_Di(地效) = κ(h) · C_L² / (π·AR·e)
```

**为什么**：诱导阻力本质是"升力矢量因为下洗而向后倾斜"，倾斜角就是诱导迎角 α_i。α_i 变成 κ 倍，阻力分量自然也变成 κ 倍。

算一下：

| h (m) | κ | 诱导阻力相对值 |
|---|---|---|
| 0.05 | 0.052 | **5.2%** |
| 0.20 | 0.292 | 29.2% |
| 0.50 | 0.612 | 61.2% |

在 5 厘米高度，诱导阻力只剩自由空气的 5%——**这就是地效飞行器升阻比能到 20 以上的原因**。

## 3.8 平尾：下洗与操纵

飞机后面有个水平尾翼（平尾），它的作用是**配平和操纵俯仰**。

### 平尾感受到的迎角

平尾在机翼后面，所以它处在机翼的下洗气流里。它的当地迎角是：

```
α_t = α + i_t - ε(h, α) + q·l_t/V
```

逐项解释：

| 项 | 含义 |
|---|---|
| `α` | 机身迎角 |
| `i_t` | 平尾安装角（本对象 -2°） |
| `-ε` | **减去下洗角**（机翼把气流往下带，平尾看到的迎角变小） |
| `+q·l_t/V` | **俯仰角速度的贡献**（飞机低头时，平尾相对气流下沉，迎角变大） |

最后一项很重要：它是**天然的俯仰阻尼**。飞机一低头，平尾迎角变大、升力变大，产生抬头力矩把它拉回来。**没有这一项，飞机就会像陀螺一样越转越快。**

### 下洗角 ε 本身也受地效影响

```
ε(h, α) = (ε0 + ε_α · α) · κ(h)
```

- `ε0`：常数部分（约 0.02 rad）
- `ε_α`：随迎角增长的部分（约 0.35）

**注意**：地效让下洗变小（乘了 κ），所以平尾看到的迎角会**变大**。这个细节在第 5 章会导致一个严重问题——**平尾在低空会产生额外低头力矩**，这正是地效高度不稳定的主因。

### 平尾升力与升降舵

```
C_Lt = a_t(h_t) · (α_t - α_L0t) + a_δe · δ_e
```

- `a_t`：平尾的升力线斜率，同样按 3.6 节公式修正，但用的是**平尾高度** `h_t = h + Δz_t`（本对象平尾比机翼高 0.30 m，因为它是抬高安装的）
- `δ_e`：升降舵偏角。**约定：正 δ_e 表示后缘向下偏**，会让平尾升力增大，产生**低头**力矩
- `a_δe = 1.60 /rad`：升降舵的操纵效能

**注意符号约定**：正的升降舵偏角 = 低头。这是航空界的标准约定（和"拉杆抬头"正好相反，因为拉杆时升降舵后缘是向上偏的）。

## 3.9 俯仰力矩：一个统一的公式

力矩的计算很容易出错，因为涉及的力多、力臂多、符号多。本工程用了一个**统一公式**，值得单独讲。

### 力矩 = 位置矢量 × 力

对机体坐标系（y 轴指向右翼），绕 y 轴的力矩是：

```
M = z·F_x - x·F_z
```

其中 `(x, z)` 是力的作用点相对于**重心**的坐标（x 向前为正，z 向下为正），`(F_x, F_z)` 是力的分量。

**这个公式怎么来的**：力矩 = r × F（叉乘）。叉乘展开后，绕 y 的分量正好是 `z·F_x - x·F_z`，另外两项是绕 x 和 z 轴的（纵向运动里我们不管）。

### 符号含义的物理解释

| 情况 | 数学 | 物理 |
|---|---|---|
| 升力（向上，F_z < 0）作用在重心**之后**（x < 0） | M = -x·F_z = (-)(-) = **正** | 抬头？ |

等等，这里要小心。我们重新推一遍：

升力向上，所以 `F_z = -L`（因为 z 轴朝下）。
作用点在重心之后，所以 `x = -l`（l 是距离，正数）。
代入：

```
M = 0 - (-l)·(-L) = -l·L < 0
```

**M < 0 意味着低头**。而物理上"在重心后面向上推"，确实会让机头**低下**去（想象跷跷板，从后面往上顶，前面就往下沉）。

**结论**：`M = z·F_x - x·F_z`，x 向前为正、z 向下为正、抬头力矩为正。这三个符号约定必须一致，否则整个模型就错了。

### 本工程包含的力矩项

| 来源 | 说明 |
|---|---|
| 机翼升力/阻力 | 作用点在气动中心 |
| 机翼自身俯仰力矩 C_mac | 弯度翼型固有的低头力矩（-0.05） |
| 平尾升力/阻力 | 力臂最长，是主要的配平手段 |
| 推力偏置 | 推力线不在重心上（本对象高 3 cm） |
| 机体力矩 | 机身细长，有小量贡献 |

**代码对应**：`wig_aero.m` 里每个力矩都按同一个公式写，只是代入不同的 `(x, z)` 和 `(F_x, F_z)`。这样不容易错。

## 3.10 三个"看不见的力"

真实的飞行器还有三个效应，本工程的处理很关键——**故意把它们放进"真实对象"但不放进"控制器模型"**。

### RAM 效应

贴地飞行时，机翼下方的空气被"困住"，压力升高，产生额外的升力。

本工程模型：

```
ΔC_L,RAM = k_ram / (1 + (h/h_ram)²)
```

- `k_ram = 0.09`：幅度
- `h_ram = 0.25 m`：特征高度

在 h = 0.05 m 时约贡献 +0.086 的升力系数（约占巡航升力的 14%）。

**关键细节**：RAM 力的作用点在气动中心**之后** 5 cm（因为高压区偏后），所以它还附带一个**低头力矩**。

### 升力非线性（失速软化）

迎角大时升力不再线性增长。本工程用平滑的 tanh 函数模拟：

```
C_L,实际 = C_Lmax · tanh( C_L,线性 / C_Lmax )
```

- `C_Lmax = 1.3`

用 tanh 而不是硬切换的原因是**可导**——数值积分和线性化都要求函数光滑。

### 参数失配

真实飞行器的气动系数和估算值总有偏差。本工程设置了：

| 参数 | 名义值 | 真实值 | 偏差 |
|---|---|---|---|
| 地效强度 A | 0.0641 | 0.045 | 地效更强 |
| 地效指数 n | 1.4622 | 1.300 | 衰减更慢 |
| 废阻力 C_D0 | 0.025 | 0.032 | +28% |
| 下洗梯度 ε_α | 0.35 | 0.45 | +29% |

### 为什么要故意制造失配

**这是整个课题成立的基石。**

如果"真实对象"和"控制器模型"完全一样，那么一个简单的动态逆控制器就能做到完美——**仿真什么也证明不了**。

只有当真实对象和模型有显著差异时，"自适应"才有存在的意义。本工程设置的失配幅度（升力差最大 13.9 N，占重量的 11.8%）代表了"工程估算式、未经 CFD 或风洞验证"的典型情况——**这也正是本工程真实的处境：地效参数只跟住了公开趋势，没有任何 CFD 数据支撑**。

## 3.11 本章小结

- 升力用无量纲系数 `L = q·S·C_L` 表示，好处是跨尺寸、跨速度通用。
- **有限翼展产生诱导阻力**：`a = a0/[1 + a0/(πARe)]`，本对象 5.90 降到 4.31。
- **地面效应的物理本质是镜像涡削弱下洗**，用系数 κ 描述。
- 选 `κ = x^n/(A+x^n)` 的理由：两端行为正确 + 可化为直线做最小二乘拟合。
- **A、n 是按公开趋势选定的工程估算值，不是 CFD/风洞标定结果**（`ge_kappa_template.csv` 由本工程解析式生成，拟合它是往返自检，不是验证）。
- **地效修正升力线斜率**：`a_w = a0/[1 + a0κ/(πARe)]`，5 cm 处增大 34%。
- 俯仰力矩统一用 `M = z·F_x - x·F_z`，符号约定必须一致。
- 真实对象还包含 RAM 效应、失速软化和参数失配——**故意不告诉控制器**。
