# 第 4 章 运动方程怎么来

第 3 章算出了"飞机受了多少力和力矩"。这一章把这些力变成"飞机怎么动"。

## 4.1 状态量怎么选（一个重要的选择）

要写运动方程，先要决定"用哪些量描述飞机的状态"。

### 三种常见的选法

| 方案 | 状态量 | 优点 | 缺点 | 是否采用 |
|---|---|---|---|---|
| A. 机体轴速度分量 | u, w, q, θ, h | 力矩方程形式最简洁 | u、w 的物理意义对控制不直观；气动力要另外换算角度 | × |
| B. 风轴（气流轴） | V, α, q, θ, h | 气动力可直接代入 | 高度环设计时还要自己算 γ | △ |
| **C. 风轴 + 航迹角** | **V, γ, α, q, h** | **高度变化率直接由 γ 给出**；气动力直接可用 | 需要多一步 θ = γ + α 的换算 | **√** |

### 为什么最终选 C

三个理由：

**理由 1：高度是核心被控量，而 `dh/dt = V·sin(γ)`。**

如果状态里只有 θ 和 α，那么 `γ = θ - α`，每次算高度变化率都要多算一次减法。虽然只是个小差别，但**控制器的外环设计直接依赖这个关系**，用 γ 做状态可以让外环设计变得非常直观。

**理由 2：气动力直接是 (V, α) 的函数。**

升力 `L = q·S·C_L(α)`，阻力 `D = q·S·C_D(α)`，动压 `q = 0.5ρV²`。如果状态用 u、w，那么 `V = √(u²+w²)`、`α = atan(w/u)`，每次算气动力都要做两次非线性运算，既慢又容易在数值上出问题。

**理由 3：θ 不是独立的。**

因为 `θ = γ + α` 是恒等式，所以 θ 是**冗余的**。把它当独立状态会让状态方程出现"0 = 0"的退化行，数值求解时雅可比矩阵奇异。

所以：**状态量取 `[V, γ, α, q, h]` 五个**，θ 随时可以用 `γ + α` 算出来。

### 还要加上两个执行器状态

除了 5 个刚体状态，还要加上：

- **T**：发动机推力（N）
- **δ_e**：升降舵实际偏角（rad）

为什么？见 4.7 节。**这是本工程调试阶段最关键的一个决定。**

最终状态向量（7 阶）：

```
x = [V, γ, α, q, h, T, δ_e]^T
```

## 4.2 沿航迹方向的方程

在航迹坐标系（一个跟着飞机转的坐标系）里，沿飞行方向应用牛顿第二定律。

**受力分析**（沿航迹方向，向前为正）：

| 力 | 表达式 | 方向 |
|---|---|---|
| 推力分量 | `T·cos(α + i_T)` | 向前（如果推力线有安装角 i_T） |
| 阻力 | `-D` | 向后 |
| 重力分量 | `-m·g·sin(γ)` | 爬升时向后 |

得到：

```
m · dV/dt = T·cos(α + i_T) - D - m·g·sin(γ)
```

**逐项检查符号**（这类方程最常错在符号上）：

- 爬升（γ > 0）时 `sin(γ) > 0`，重力项为负 -> 减速 √
- 俯冲（γ < 0）时 `sin(γ) < 0`，重力项为正 -> 加速 √
- 推力越大越加速 √；阻力越大越减速 √

## 4.3 法向（垂直航迹）的方程

这是**最容易漏掉一项**的地方。很多人写 `m·V·dγ/dt = L - mg·cos(γ)` 就交卷了，忘了这是曲线运动。

### 曲线运动的加速度

飞机沿弯曲航迹飞行时，速度**大小**和**方向**都在变。加速度分解成两个垂直分量：

- **切向加速度** `dV/dt`（改变速度大小）
- **法向加速度** `V·dγ/dt`（改变速度方向，即向心加速度）

**向心加速度的推导**（帮你回忆一下）：

物体以速度 V 沿半径 R 的圆运动，转一圈用时 `T = 2πR/V`。速度矢量转一圈也是 2π，所以角速度 `ω = 2π/T = V/R`。向心加速度 `a = V·ω = V²/R`。

因为 `ω = dγ/dt`，且 `R = V/(dγ/dt)`，所以 `a = V² / (V/(dγ/dt)) = V·(dγ/dt)` √

### 法向方程

法向（向上为正）受力：

| 力 | 表达式 |
|---|---|
| 升力 | `L` |
| 推力法向分量 | `T·sin(α + i_T)` |
| 重力法向分量 | `-m·g·cos(γ)` |

得：

```
m · V · dγ/dt = L + T·sin(α + i_T) - m·g·cos(γ)
```

**平飞时验算**（γ = 0，加速度为零）：

```
L + T·sin(α+i_T) = m·g
```

即"升力加上推力法向分量等于重力"——这就是平飞的条件 √

**机械类比**：把航迹看成一座拱桥，飞机在上面跑。桥对飞机的"支撑"就是升力。桥越弯（dγ/dt 越大），需要的支撑力越大。

## 4.4 迎角方程

迎角是"机体轴和气流方向的夹角"，所以它的变化率取决于**机头转得多快**和**航迹转得多快**之差。

由恒等式 `α = θ - γ`（注意 θ 的定义是 `θ = γ + α`，所以 `α = θ - γ`）对时间求导：

```
dα/dt = dθ/dt - dγ/dt = q - dγ/dt
```

其中 `q = dθ/dt` 是俯仰角速度。

**物理含义**：

- 机头转得快（q 大）-> 迎角增大
- 航迹转得快（dγ/dt 大）-> 迎角减小

**举例**：飞机平飞时突然把机头拉起（q > 0）。航迹还没来得及弯（dγ/dt ≈ 0），所以迎角立刻增大，升力增大——这就是"拉杆上升"的机理。

## 4.5 俯仰方程

刚体绕横轴的转动：

```
I_yy · dq/dt = M
```

- `I_yy`：绕 y 轴的转动惯量，本对象 1.15 kg·m²
- `M`：总的俯仰力矩（抬头为正），由第 3 章的 `M = z·F_x - x·F_z` 累加得到

**这一条方程是控制器的主战场**：升降舵主要通过改变 M 来控制飞机，所以第 7 章的动态逆控制律就是围绕这个方程设计的。

## 4.6 高度方程

由 2.2 节的运动学关系：

```
dh/dt = V · sin(γ)
```

**注意这是纯运动学**，不涉及力。它说明：想改变高度，唯一的手段是改变 γ。

**这条方程决定了控制器的外环结构**：外环把"高度误差"翻译成"航迹角指令"。

## 4.7 执行器方程（为什么必须建）

刚体方程写完了，但**真实飞机不是理想的**：舵不会瞬间转到指令位置，发动机推力也不会瞬间建立。

### 舵机（一阶惯性环节）

```
τ_e · dδ_e/dt = sat(δ_e,指令) - δ_e
```

- `τ_e = 0.05 s`：舵机时间常数
- `sat(·)`：位置限幅，本对象 ±25°

**为什么航空舵机是一阶惯性**：它是电液或电机驱动，有惯量和阻尼，响应速度有限。写成一阶惯性是最简单的合理模型：

- 指令突变 -> 舵面按指数规律趋近目标
- 时间常数 0.05 s -> 约 0.15 s 到达目标（3τ）

### 发动机

```
τ_T · dT/dt = T_指令 - T
```

- `τ_T = 0.15 s`
- 推力范围 0 ~ 35 N

### 为什么必须建模（血的教训）

本工程调试时，**几乎所有发散问题都和这两个滞后有关**。原因在 2.8 节讲过：**滞后吃掉相位裕度**。

给个具体数字：在 6.5 rad/s 的频率上，0.05 秒舵机滞后贡献的相位滞后是：

```
0.05 × 6.5 = 0.325 rad = 18.6°
```

看起来不多。但加上俯仰角滤波器、角速度滤波器、采样延迟，总滞后可以轻松超过 60°。而 ζ = 0.3 的系统相位裕度本来就只有约 33°——**一加就翻车**。

**如果不在模型里建执行器滞后，仿真会给出一个"性能很好"的假象，实际上天就摔。**

## 4.8 完整的七阶模型

把上面所有方程汇总：

```
dV/dt   = [ T·cos(α+i_T) - D - m·g·sin(γ) ] / m
dγ/dt   = [ L + T·sin(α+i_T) - m·g·cos(γ) ] / (m·V)
dα/dt   = q - dγ/dt
dq/dt   = M / I_yy
dh/dt   = V·sin(γ)
dT/dt   = (T_指令 - T) / τ_T
dδ_e/dt = sat( (δ_e,指令 - δ_e)/τ_e , 速率限幅 )
```

**代码对应**：`wig_dynamics.m`，逐行就是这个。

### 数值积分：为什么要用定步长 RK4

把上面这组方程交给计算机求解，需要选一个积分算法：

| 方法 | 优点 | 缺点 | 是否采用 |
|---|---|---|---|
| 欧拉法 | 最简单 | 精度一阶，步长必须极小 | × |
| ode45（变步长 RK45） | 自适应步长，通用 | **步长不固定 -> 结果不可复现**；和 Simulink 定时调度不一致 | × |
| **定步长 RK4** | **四阶精度；步长固定 -> 完全可复现；与 Simulink 的 ode4 一致** | 需要自己估计合适步长 | **√** |

**RK4 的公式**（不用记，知道它是"用四个斜率的加权平均"就行）：

```
k1 = f(x)
k2 = f(x + h/2·k1)
k3 = f(x + h/2·k2)
k4 = f(x + h·k3)
x_新 = x + h/6·(k1 + 2k2 + 2k3 + k4)
```

**为什么选步长 1 ms**：

- 舵机时间常数 0.05 s，1 ms 相当于每 50 步采样一次 -> 足够
- 控制器采样 200 Hz（5 ms），1 ms 让每个控制周期有 5 个积分步 -> 够用

## 4.9 本章小结

- 状态量取 **`[V, γ, α, q, h, T, δ_e]`**，选 γ 而不选 θ 是因为高度环设计需要它，且 θ 冗余。
- 纵向运动方程有三条主线：**切向 F=ma、法向向心加速度、绕横轴转动**。
- **法向方程里的 `m·V·dγ/dt` 是最容易漏的一项**。
- `dα/dt = q - dγ/dt` 说明迎角是"机头转角和航迹转角之差"。
- **执行器滞后必须建模**，否则仿真会给出虚假的好结果。
- 数值积分用**定步长 RK4**，保证可复现且与 Simulink 一致。
